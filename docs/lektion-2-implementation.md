2. **Existing Supabase/data model:** retain `content_lessons` / `content_items` JSONB catalog with published-row RLS. Store typed content metadata on items and activity references/ordering in `content_lessons.data.learningFlows`. Keep `learner_lesson_states` and the existing history/derived progress system. See [inventory and design](lektion-2-content-inventory.md) for objectives, provenance, raw data, interactions and exclusions. Student/Studentin reuses the core concept. Nine additional compound examples retain worksheet_support. Distinguish source_scope in data and show teacher/worksheet badges in the flow. Phone digits are composed practice examples from the same number IDs.

7. **Migrations:** `20261007010000_l02_learning_content.sql` seeds verified content/flow with version guards; `20261007020000_l02_lesson_states.sql` extends the existing state-key check constraint, retaining L01 keys/RLS. Both were applied using the project's migration scripts and verified through live read-only database/API checks.
8. **Seed records:** L02 now has 109 published records (92 inserted, 17 legacy IDs enriched). Breakdown: 41 numbers, 11 profession concept records, 8 pronouns, 2 verbs, 3 phrase/question records, 6 statuses, 29 teacher profession records, 1 Traumberuf, 8 preserved legacy feminine-form records. Existing feminine IDs remain valid and are exposed when their form pair is learned; no new duplicate practice records were created for these legacy forms. All 109 have source tags/provenance. Total configured catalog: 12 lessons, 352 items. Flows contain 113 vocabulary and 22 grammar activities; these are learning-completion counts, not mastery.
9. **Assets:** 11 original SVG profession scenes in `public/images/lektion-2-professions`: engineer, mechanic, student, journalist, hairdresser, architect, doctor, teacher, seller, waiter, courier. No copied coursebook art, number images or new audio files. Audio uses the existing German synthesis helper; configured file references take precedence when later supplied. Thai readings are editorial aids, not claims of verbatim source transcription.
10. **Reusable components:** `NumberChoice` accepts referenced options/prompts for number, pronoun, image and sentence discrimination; `AudioChoice` handles static files or the shared German voice; `PairMatching` supports word/image, explicit form pairs and conjugation, using drag or tap, interchangeable duplicate conjugation tokens, green locked pairs and brief red retry feedback. `GuidedFlow` composes catalog-configured interactions and persists through the existing provider.
11. **Flow:** Wortschatz: grouped base/tens number recognition + sound → reverse recognition → compound patterns → Handynummer → three small profession groups, each word/image → image/word → gender forms → teacher statuses → extra teacher forms → Traumberuf. Grammatik: eight pronoun situation choices → arbeiten → machen → sein reuse → Was? → Beruf response/completion → status/job contrast → dream-job retrieval and optional personal writing. Exactly two L02 top-level skill entries, no category menu layers.
12. **Persistence:** correct interactions expose content using existing `learning_action('expose')`; Learn creates no Practice attempts or mastery. Account-scoped activity IDs, learned content IDs, partial pair IDs and resume index use the existing table/provider/pending-write queue. Back/revisit do not erase completion or regress resume. On reopening/refresh, state normalization finds the first unfinished activity; completed flows reopen their ending. A partial conjugation board does not mark the whole verb learned. Load/save failures retain existing retry behavior. Legacy import remains restricted to the original L01 keys. Optional personal writing is deliberately not stored.
13. **Validation:** all 135 L02 browser activities passed, including incorrect feedback with no revealed correct choice, retry, matching, drag/tap conjugation, audio choice, partial-pair reload, Back, resume, full completion, and mobile overflow/screenshots. Unit tests: 19 passed (18 existing + L02 catalog/state/RLS test). Existing learning DB and lesson-state DB scripts passed. Existing L01 verb browser regression passed. Test-workspace tests: 2 passed. `git diff --check` passed. Type generation, `tsc --noEmit`, and optimized Next build passed via repository-local Node 20.20.2. No lint script exists. Browser synthesis is mocked to validate playback/selection behavior; this is not an acoustic-quality assessment. Artifacts are in ignored `test-results/l02-*-mobile.png`.
14. **Intentionally not done:** L01 redesign, Alphabet changes, L03+ material, new progress architecture, mastery/scoring/spaced repetition, general grammar expansion, production learner test writes, static audio pipeline, copied book art, auxiliary missing PDFs, correcting ambiguous source terms by guessing. Not all incidental vocabulary in the book's prose becomes a new core card.
15. **Remaining source uncertainty:** no complete printed machen conjugation table was located in the inspected L02 pages. Its full user-requested forms apply the teacher's attested regular-ending system, with provenance documented in the inventory; similarly arbeiten's full system extends the source's partial table. The teacher's `Schönheitkönigin` spelling and rich-unemployed labels are excluded rather than silently corrected/promoted to profession pairs. es is excluded because the actual L02 presentation does not include it. Some opposite profession forms are teacher-attested only; this is tagged per form rather than represented as book evidence. The extra Buch/misnamed worksheet PDFs remain unavailable, but the requested Moment, actual Lektion 1–12 worksheet and teacher slides were available and used.
