# รูปแบบบทเรียนผัน Verb มาตรฐาน

บันทึกวันที่ 9 ตุลาคม 2026 ตามคำขอผู้ใช้ ใช้กิจกรรม Verben ของ **Lektion 1** เป็นแม่แบบสำหรับหน้าเรียนผันกริยาในเมนูบทเรียนทุกบท

เอกสารนี้ขยายข้อกำหนดใน [PRODUCT_BASELINE.md](PRODUCT_BASELINE.md) และใช้เป็นนิยามเมื่อสั่งว่า **“ใช้รูปแบบบทเรียนผัน Verb แบบบท 1”** หรือ **“ใช้รูปแบบบทเรียนผัน Verb มาตรฐาน”**

## ความหมายของคำสั่ง

นำการจัดหน้าและพฤติกรรมจับคู่ของบท 1 มาใช้กับกริยาของบทที่กำลังพัฒนา โดยใช้ข้อมูลกริยาและระบบ Progress เดิมของบทนั้น ไม่สร้างแบบทดสอบแยกหรือคัดลอกคำกริยาบท 1 ไปแทนเนื้อหาบทอื่น

## ลำดับหน้าและเนื้อหา

1. เข้า Grammatik แล้วเลือกการ์ด **Verben**
2. บท 1 เปิดหน้าหลักการผันรวมก่อนเริ่ม: ส่วนหลักของคำ, Endung และตารางประธาน กด **หน้าถัดไป** แล้วเข้ากระดานผัน
3. ใช้แท็บชื่อกริยาเรียงต่อกัน มีเส้นใต้แท็บปัจจุบัน รองรับลูกศรคีย์บอร์ดและการกลับดูคำที่เรียนแล้ว
4. เหนือกระดานของแต่ละคำมีคำกริยารูป Infinitiv ความหมายไทย หมายเหตุที่จำเป็น และตัวอย่างเยอรมันพร้อมคำแปลไทยในกล่องเดียวกัน ไม่แยกหน้าแนะนำกริยารายคำให้กดผ่านอีกขั้น
5. หลังเรียนครบ มีตารางสรุปประธานกับรูปผันของกริยาที่เรียน

## กระดานจับคู่: ประธานมีช่องรับรูปผันในแถวเดิม

หน้ากว้างจัดเป็นสองฝั่ง:

| ฝั่งประธาน: ลำดับคงที่ | ฝั่งรูปกริยา: สุ่มลำดับ |
| --- | --- |
| ich + [ช่องวางคำตอบ] | บัตรรูปผันที่ยังไม่ได้ใช้ |
| du + [ช่องวางคำตอบ] | บัตรรูปผันที่ยังไม่ได้ใช้ |
| er / sie / es + [ช่องวางคำตอบ] | บัตรรูปผันที่ยังไม่ได้ใช้ |
| wir + [ช่องวางคำตอบ] | บัตรรูปผันที่ยังไม่ได้ใช้ |
| ihr + [ช่องวางคำตอบ] | บัตรรูปผันที่ยังไม่ได้ใช้ |
| sie / Sie + [ช่องวางคำตอบ] | บัตรรูปผันที่ยังไม่ได้ใช้ |

- ผู้เรียนลากบัตรรูปผันลงช่องข้างประธาน หรือแตะบัตรรูปผันแล้วแตะช่องประธาน รองรับคอมและมือถือ
- มือถือวางส่วนประธานและคลังรูปผันต่อกันในแนวตั้งได้ แต่แต่ละประธานยังมีช่องคำตอบของตัวเอง
- รูปผันที่สะกดเหมือนกัน เช่น kommen ของ wir และ sie / Sie ใช้แทนกันได้ ไม่ผูกคำตอบกับตำแหน่งหรือ ID ของบัตรอย่างเดียว ใช้หนึ่งบัตรต่อหนึ่งช่อง
- **ตอบถูก: รูปผันค้างในช่องข้างประธานเดิม** ช่องเป็นสีเขียว ล็อกคำตอบ และนำบัตรที่ใช้แล้วออกจากคลัง ไม่ย้ายคู่ที่ถูกไปเป็นรายการด้านบนหรือแยกออกจากแถวประธาน
- **ตอบผิด:** ช่องและบัตรที่เลือกแสดงสีแดงชั่วครู่ แล้วให้ลองใหม่ บัตรยังอยู่ในคลัง ไม่ใส่เฉลยที่ถูกลงช่องแทน
- ตรวจทันทีรายคู่ ไม่ต้องมีปุ่มตรวจ และไม่เปิดเฉลยทั้งกระดานก่อนเรียนครบ
- จับคู่ครบแล้วคงกระดานเดิมให้ทบทวน พร้อมปุ่ม **หน้าถัดไป** ไม่เปลี่ยนหน้าอัตโนมัติ เมื่อเปลี่ยนหน้ากลับต้นหน้าใหม่

## สีและเสียง

- ใช้กติกากลาง Endung และตัวอักษรที่เปลี่ยนรูปเป็นสีแดงในคำอธิบาย/ตัวอย่างการผัน/ตารางสรุป เช่น sind เน้น in สีแดง โดยคงกติกาไม่เฉลยคำตอบล่วงหน้า
- สีเขียวของช่องหมายถึงจับคู่ถูก ส่วนสีแดงภายในคำหมายถึงส่วนรูปคำที่ต้องสังเกต
- มีสัญลักษณ์ลำโพงให้ฟังคำกริยา ตัวอย่าง และรูปผันได้
- จับคู่ถูกอ่านประธานพร้อมรูปผันทันที เช่น ich komme ทั้งการแตะและลากวาง กดคู่ที่ถูกเพื่อฟังซ้ำได้โดยไม่ถอนคำตอบออกจากช่อง
- การตอบผิดไม่อ่านเฉลย การ reload หรือคืนสถานะไม่เล่นเสียงเอง และการฟังไม่สร้างหลักฐานเรียนหรือจำได้เพิ่ม

## การกลับมาเรียนต่อและเรียนซ้ำ

- ใช้ระบบจัดเก็บ Progress ของโปรเจกต์ คง item IDs และประวัติเดิม ไม่สร้างระบบความคืบหน้าซ้ำ
- กลับมาแล้วคืนกริยาและคู่ที่จับไว้ คู่ที่ถูกยังอยู่ในช่องเดิม การจับคู่ครั้งเดียวไม่ถือว่าจำได้อย่างมั่นคง
- การเรียนซ้ำล้างเฉพาะคำตอบรอบกิจกรรมตามขอบเขตที่เลือก คงสถานะเคยเรียนและประวัติ Practice/mastery
- คงตารางสรุปและการย้อนดูบทที่เรียนแล้วตามพฤติกรรมของบท 1
