# คำศัพท์บท 13 พร้อมใช้งาน

วันที่ 22 ตุลาคม 2026

## สิ่งที่เปิดใช้

คำศัพท์ 49 คำ ครอบคลุม 137 ข้อ เลือกความหมาย 49 ข้อ Artikel 39 ข้อ และพิมพ์คำ 49 ข้อ แบ่งตามกลุ่มในบทเรียน บัญชีผู้เรียนฝึกได้เฉพาะคำที่เรียนแล้วจากการจับคู่ภาพหรือ ItemExposure

หลังเรียนกดทำแบบฝึกหัดเพื่อเข้าโจทย์ทันที หัวข้อละไม่เกิน 5 ข้อ สามกลุ่มภาพรวม 15 ข้อ หากเรียนคำเพิ่มเติมแล้วด้วยจะรวมได้สูงสุด 20 ข้อ มีจุดพักระหว่างหัวข้อ ชุดแนะนำครั้งต่อไปมีไม่เกิน 10 ข้อ แยกผลความหมาย Artikel และการพิมพ์ออกจากกัน

บันทึกรอบ ร่างคำตอบ คำตอบแรก ความมั่นใจ และจุดพักเข้าบัญชี พร้อมสำรองในเครื่องและส่งซ้ำเมื่อเชื่อมต่อได้ ยังไม่ใช้ผลนี้แทน KnowledgeState หรือคะแนนความชำนาญหลัก และไม่เปลี่ยนผลเรียนเป็นคะแนนอัตโนมัติ

## ฐานข้อมูล

ติดตั้งกับฐานบัญชีจริงแล้ว โดยไม่มีการย้ายหรือแก้ประวัติการเรียนเดิม:

1. `20261022000000_practice_account_sessions.sql`
2. `20261022010000_vocabulary_practice_banks.sql`
3. `20261022020000_vocabulary_session_validation.sql`

ฐานข้อมูลตรวจสิทธิ์คำที่เรียนแล้ว ข้อและเวอร์ชันกับคลังคำตอบ และตรวจคำตอบอีกครั้ง ไม่ยอมรับการแก้คำตอบที่ถูกต้องใน payload หรือการจบรอบที่ยังตอบไม่ครบ ใช้ RLS แยกบัญชีและไม่เปิดคลังตรวจคำตอบให้ anonymous/authenticated อ่านโดยตรง

คำศัพท์ที่เผยแพร่ในฐานจริง 49 รายการตรงกับ word/meaning ในคลังโปรเจคครบทุก ID ประวัติรอบเก่าคงอยู่ และคำตอบแรกไม่ถูกข้อมูลเก่าทับ

คำสั่งติดตั้งซ้ำ: `npm run db:migrate-practice` ต้องใช้ Node 20.9 ขึ้นไปและ DATABASE_URL ของฐานเป้าหมายใน `.env.local` สคริปต์แจ้ง PostgREST โหลด schema ใหม่หลังติดตั้ง

## การเปิดหน้าเว็บ

- ใช้บัญชีจริงบนเครื่อง: `http://localhost:3000/practice/L13/vocabulary`
- บัญชีทดลอง: `http://localhost:3002/practice/L13/vocabulary`

production build เปิดคำศัพท์บท 13 ให้บัญชีผู้เรียนโดยค่าเริ่มต้น. กำหนด `NEXT_PUBLIC_L13_VOCABULARY_PRACTICE=false` ก่อน build เพื่อปิดเฉพาะคลังนี้ หรือกำหนด `true` เพื่อเปิดใน development. การเปิดคำศัพท์ไม่เปิดคลังไวยากรณ์ทดลองให้บัญชีทั่วไป

ปิดการเปิดใช้ด้วยค่า `false` แล้ว build/start ใหม่ โดยไม่ลบข้อมูลรอบฝึก บัญชีทดลองในพื้นที่ทดสอบยังทดสอบได้ตามเดิม

ฐานข้อมูลจริงติดตั้ง migration ที่จำเป็นแล้ว. สถานะการเผยแพร่ล่าสุดให้ดู `docs/CHANGELOG_RE.md`

## หลักฐานตรวจ

- `tests/vocabulary-practice-database.mjs`: ข้อที่ยังไม่เรียน การแก้คำตอบใน payload รูปแบบร่างที่ไม่ถูกต้อง คำตอบแรก การจบรอบ ความมั่นใจ RLS และการตรวจคำตอบครบ 137 ข้อ รวมคำตอบที่ยอมรับ 143 รูปแบบ
- `tests/l13-vocabulary-practice-browser.mjs`: จับคู่ภาพจริง เริ่มจากหน้าเรียน ฝึกครบกลุ่ม เฉลยไทย ไม่มีคำแปลเฉลยก่อนตอบ ทำต่อสองเบราว์เซอร์ ชุดแนะนำ 10 ข้อ หน้าจอ 390px และการแยกบัญชี รวมตรวจ accepted answers ของทั้ง 137 ข้อ
- `tests/vocabulary-learner-rollout-browser.mjs`: จำลองเส้นทาง UI ที่ไม่ใช่บัญชีทดลอง เปิดคำศัพท์และซ่อนไวยากรณ์ทดลอง โดยไม่สร้างบัญชีผู้เรียนจริง
- `tests/account-practice-browser.mjs`: ทดสอบไวยากรณ์เดิมซ้ำ การส่งข้อมูลเก่า การลองส่งใหม่ จุดพักและการจบรอบ 15 ข้อ
- `tests/vocabulary-production-smoke.mjs`: production build เปิดหน้าเข้าสู่ระบบจริง ไม่มีแบนเนอร์ทดลองและไม่มี page error โดยไม่ใช้ข้อมูลเข้าสู่ระบบของผู้เรียน
- production build และ TypeScript ผ่าน

แหล่งอ้างอิงและการออกแบบรายข้ออยู่ใน `docs/exercise-mapping/L13_VOCABULARY_PRACTICE.md` และ manifest ภายใน ไม่มีการอ้างว่าโจทย์สร้างใหม่เหล่านี้เป็นการคัดโจทย์สำนักพิมพ์
