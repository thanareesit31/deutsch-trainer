# ประโยคและสำนวนบท 13

สถานะ 22 ตุลาคม 2026: รอบใหม่หัวข้อละห้าข้อพร้อมทดลองบน localhost:3002. ไม่ได้อัปเดตฐานบัญชีจริงหรือเผยแพร่ออนไลน์ในงานนี้.

## ทางเข้าและลำดับฝึก

เรียนที่ /learn/L13/phrases. เมื่อเรียนครบ 29 สำนวน ปุ่มทำแบบฝึกหัดเปิด /practice/L13/phrases/basic ทันที. สี่หัวข้อเดิม หัวข้อละเลือกตอบ 2 ข้อ จับคู่ 2 คู่ และเรียงคำ 1 ข้อ รวม 20 ข้อ. สองคู่แสดงในหน้าเดียวแต่นับแยก ทำให้มี 16 หน้ากิจกรรมและจุดพักระหว่างหัวข้อสามครั้ง.

เลือกหัวข้อเองที่ /practice/L13/phrases. ชุดแนะนำใหม่มีไม่เกินสิบข้อและไม่แยกคู่จับคู่. รอบเก่าทำต่อได้ หรือกดเริ่มรอบรูปแบบใหม่เพื่อเก็บรอบเดิมเป็น archived พร้อมผลเดิม. คำแนะนำไม่เสนอรอบ archived ให้ทำต่อ.

## ข้อมูลและฐานบัญชี

ยึดประโยคและคำแปลเดิมใน supabase/seed/catalog.json. คำถาม บริบท ตัวลวง และข้อมูลสถานที่เป็นโจทย์เว็บแต่งเพิ่มและบันทึกที่มารายข้อภายใน docs/exercise-mapping/L13_PHRASES_TOPIC_SEQUENCE.md และ l13-phrases-bank.json. รอบแรกประเมิน 20 เป้าหมายจากสำนวนที่เรียนทั้งหมด 29 รายการ; ไม่รับรอง mastery ของทุกสำนวน.

Migration 20261022050000_phrase_topic_sequence.sql เพิ่มนิยามใหม่และตรวจ interaction/matchGroupId/ตัวเลือกจับคู่ฝั่งเซิร์ฟเวอร์. คงนิยาม legacy 98 ข้อ. คำตอบแรก ความมั่นใจ ร่างคู่ที่เลือก จุดพัก และรอบค้างบันทึกแยกบัญชีและมีสำรองในเครื่อง. คำถามที่ใช้สำนวนเดิมเป็นบริบทต้องมี exposure ของส่วนนั้นด้วย แยก supporting phrases ออกจาก target ที่วัดผลเพื่อไม่ปิดกั้นโจทย์เพียงเพราะใช้คำถามประกอบซ้ำ.

## การตรวจ

ฐานข้อมูลตรวจคำตอบอัตโนมัติ 114 รายการ คือ 20 ข้อใหม่และ 94 ข้อ legacy ที่มีเฉลยตายตัว. ผ่านการตรวจการปลอมกลุ่ม/ตัวเลือกจับคู่ ผลแยกรายคู่ เงื่อนไขการเรียนก่อนทำ และการแยกบัญชี. งานเขียน legacy อีกสี่ข้อไม่อยู่ในจำนวนการตรวจคำตอบตายตัว.

เบราว์เซอร์ตรวจรอบ 20 ข้อ ลำดับง่ายไปยาก เป้าหมายไม่ซ้ำ การบันทึกคู่ค้างและทำต่ออีกเบราว์เซอร์ ผลสองคู่แยกกัน จุดพักสามครั้ง การเก็บผลเก่าเมื่อเริ่มใหม่ ชุดรายวันครบคู่ หัวข้อเดี่ยวห้าข้อ การเว้นคู่ที่ยังเรียนไม่ครบ และหน้าจอมือถือ 390px. ภาพตรวจอยู่ใน .tools/l13-phrases-matching-desktop.png และ .tools/l13-phrases-matching-mobile.png.

คำสั่งตรวจ: npm run test:phrase-practice-db, npm run test:phrase-practice-browser และ npm run test:vocabulary-practice-db. ใช้ Node 20 ขึ้นไป. TypeScript และการตรวจ whitespace ผ่าน. การทดสอบคำศัพท์ร่วมผ่าน 137 ข้อและ 143 คำตอบ.
