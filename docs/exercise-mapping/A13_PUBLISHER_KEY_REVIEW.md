# A1.3: การตรวจเฉลยสำนักพิมพ์ของทะเบียน 545 ระเบียน

วันที่ตรวจ: 21 ตุลาคม 2026

## ความหมายของตัวเลข

`a13-item-level-source-audit.json` มี **545 หน่วยตรวจต้นทาง** จากหนังสือ 4 แหล่งที่เลือกไว้. หน่วยหนึ่งอาจเป็นช่องตอบหนึ่งช่อง กิจกรรมทั้งหน้า กลุ่มคำตอบ หรือตัวอย่างที่หนังสือทำให้ดูแล้ว. จึงไม่ใช่คลังโจทย์เว็บ 545 ข้อ. `a13-publisher-key-review.json` มีหนึ่งรายการต่อหน่วยตรวจต้นทาง พร้อมตำแหน่งเฉลย สถานะการเทียบ และ `a13SourceDisposition` ที่บอกว่าควรใช้เป็นแหล่งแต่งโจทย์ A1.3 อย่างไร. ทุกระเบียนมี `webQuestionReady: false` เพราะการเทียบเฉลยของหนังสือยังไม่ใช่การแต่งและตรวจโจทย์ใหม่สำหรับเว็บ.

| สถานะ | จำนวน | ความหมาย |
|---|---:|---|
| `source_slot_and_publisher_fixed_key_crosschecked` | 105 | ตรวจภาพช่องตอบและเทียบคำตอบตายตัวกับเฉลย: Arbeitsbuch 71, Grammatik aktiv 34 |
| `source_row_and_publisher_solution_compared` | 14 | ตรวจรูปประโยคจากเฉลย: Arbeitsbuch 7, Grammatik A1 – das Training 7; เก็บเฉพาะจุดไวยากรณ์ที่ตรวจ ไม่ถอดประโยคทั้งข้อ |
| `source_activity_and_publisher_solution_compared` | 5 | เทียบรูปแบบของกิจกรรมหลายคำตอบกับเฉลย Arbeitsbuch; ยังไม่แยกเป็นโจทย์เว็บ |
| `publisher_activity_key_located_answer_not_crosschecked` | 46 | พบกิจกรรมในเฉลย Arbeitsbuch แต่ยังไม่เทียบแต่ละคำตอบ |
| `publisher_solution_section_located_item_not_crosschecked` | 333 | พบหน้าเฉลยของหนังสือเสริม แต่ยังไม่เทียบคำตอบของระเบียนนั้น |
| `publisher_open_answer` | 22 | สำนักพิมพ์ให้ตัวอย่างหรือระบุว่าตอบได้อิสระ; ต้องมีเกณฑ์ตรวจหลายคำตอบ |
| `publisher_no_answer_entry` | 3 | กิจกรรมฟัง/พูด/ทวนเสียงที่ไม่มีรายการเฉลย |
| `printed_model_excluded` | 17 | หนังสือพิมพ์คำตอบตัวอย่างไว้แล้ว; ไม่ใช่โจทย์ใหม่ |

ผลคัดด้านขอบเขตเป็นอีกมิติหนึ่ง: `in_scope` 107, `partial` 151, `adapt` 70, `review_only` 99, `asset_required` 23, `exclude_level` 78, และ `worked_example` 17. ระเบียนที่ตรงหัวข้อยังต้องแต่งข้อความใหม่ ตรวจเฉลยของข้อความใหม่นั้น และผูกกับหัวข้อ/ทักษะก่อนเข้าสู่คลังเว็บ.

ระเบียน `in_scope` ทั้ง 107 รายการมีผลตรวจเฉลยแล้วในระดับที่โครงสร้างต้นทางรองรับ: 85 ช่องคำตอบตายตัว, 14 แถวประโยค, 5 กิจกรรมหลายคำตอบ และ 3 งานที่เฉลยให้เพียงตัวอย่าง/คำตอบอิสระ. การตรวจนี้รับรองรูปแบบและขอบเขตของแหล่งอ้างอิงเท่านั้น.

## เฉลยที่ใช้ตรวจ

- Momente Arbeitsbuch A1.2: [เฉลยสำนักพิมพ์ Hueber](https://edit.hueber.de/media/36/Momente_AB_A1_2_Loesungen.pdf), หน้าพิมพ์ 2–5 สำหรับบท 15–18. ส่วนของบท 13–14 มีในหน้า 1 แต่ไม่รวมอยู่ในทะเบียน 545 ระเบียนนี้.
- Momente Kursbuch A1.2: [เฉลยสำนักพิมพ์ Hueber](https://www.hueber.de/media/36/Momente_A1_2_KB_Loesungen.pdf). ทะเบียน Kursbuch 34 กิจกรรมอยู่ในไฟล์แยก จึงไม่ถูกนับใน 545 ระเบียน.
- Grammatik aktiv A1–B1: หมวด `Lösungen` ใน PDF ที่ผู้ใช้ให้, หน้า PDF 198–230. สำหรับบทที่ใช้ในทะเบียนนี้ จุดเฉลยอยู่หน้า PDF 199, 200, 204, 205 และ 209. หน้าเฉลยระบุในแต่ละระเบียน.
- Grammatik A1 – das Training: หมวด `Lösungen` ใน PDF ที่ผู้ใช้ให้, หน้า PDF 75–80. หน้าเฉลยรายบทอยู่ในแต่ละระเบียน.
- Schreiben A1 – das Training: หมวด `Lösungen` ใน PDF ที่ผู้ใช้ให้, หน้า PDF 71–76. งานเขียนบางข้อมีเพียงตัวอย่างคำตอบ.

ข้อมูลอ้างอิงและคำตอบที่ถอดเพื่อตรวจเก็บไว้ใน metadata ภายในโปรเจกต์เท่านั้น ไม่แสดงใน UI ผู้เรียน.

## เกณฑ์เปลี่ยนจากระเบียนต้นทางเป็นโจทย์เว็บ

1. เลือกเฉพาะขอบเขตที่ตรงบทและทักษะ; ตัดตัวอย่างที่ทำให้ดูแล้วและบทที่เกินระดับ.
2. แยกหนึ่งการกระทำที่ผู้เรียนต้องตอบต่อหนึ่ง question ID. กิจกรรมที่ยังอยู่ระดับทั้งกิจกรรมหรือหลายช่องต้องแยกก่อน.
3. แต่งบริบท ประโยค ตัวเลือก ภาพ และเสียงใหม่ตามรูปแบบที่ตรวจพบ โดยไม่คัดลอกหน้าโจทย์.
4. บันทึกเฉลยของโจทย์เว็บเอง, คำตอบที่ยอมรับได้, เหตุผล, รูปแบบการตอบ, subskill, difficulty และ provenance ภายใน.
5. ตรวจโจทย์เว็บกับกฎและผู้ตรวจอีกครั้ง รวมทั้งกรณีหลายคำตอบ. หลังผ่านจึงตั้งสถานะพร้อมใช้และเปิดใน Practice; การเทียบเฉลยต้นฉบับอย่างเดียวไม่ผ่านขั้นนี้.

คลังทดลองไวยากรณ์ 90 ข้อที่มีอยู่แล้วอยู่ในไฟล์ bank แยกและยังมีสถานะ prototype. ไม่ถูกนำไปรวมเป็น 545 ข้อหรือเปิดใช้จริงจากการตรวจครั้งนี้.
