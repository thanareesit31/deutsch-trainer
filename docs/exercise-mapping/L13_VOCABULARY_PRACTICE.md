## สิ่งที่วัด

### ชุดใช้คำศัพท์ในบริบท (24 October 2026)

มาตรฐานภาพคำนาม: ตัวเลือกที่แสดง Artikel และเฉลยใช้ `ArticleDot` เดิมตาม Artikel และ `pluralOnly` จาก catalog พร้อมแถบ `ArticleLegend` ตรึงเหนือความคืบหน้าในทุกกิจกรรมของชุดขั้นสูง. เป็นการคืนมาตรฐานการแสดงผลและตัวช่วยเดิมของโปรเจกต์ โดยรักษา activity/response/target IDs และผลครั้งแรก. ไม่สร้างหลักฐานทักษะเลือก Artikel จากโจทย์ที่แสดง Artikel หรือจุดสีให้แล้ว.

การแก้หน้าตากิจกรรมภาพ: ใช้คำถามเยอรมันด้านบนครั้งเดียวและภาพซ้าย/ตัวเลือกขวาบนจอใหญ่. คำในตัวเลือกและเฉลยอ่าน `answer` จาก catalog ตาม item ID เพื่อแสดง Artikel ถูกต้อง. การให้คะแนนยังวัดการจำแนกคำจากภาพ ใช้ response ID และคำตอบเชิง ID เดิมทั้งหมด; การแสดง Artikel เป็นตัวช่วยที่ให้ไว้ ไม่ได้วัดการนึกเพศเอง และไม่สร้างหลักฐานทักษะ Artikel เพิ่ม. ไม่มีการเปลี่ยนคิวหรือผลเก่า.

เพิ่มรูปแบบที่เจ็ดภายหลัง: `crossword-city-places` เป็นปริศนาคำศัพท์มี 6 แถว ให้เติมตัวอักษรจากคำใบ้แล้วอ่านคำจากแนวตั้งที่ระบายสี. อ้างกลไก AB หน้า 6 / PDF 5, L13/3b โดยแต่งคำใบ้และเลือกคำใหม่ในคลังบท 13. เก็บคำตอบและร่างรายแถว ไม่เผยรูปคำก่อนตรวจ และใช้คำที่เรียนแล้วทั้งคำในแถวกับคำแนวตั้ง. จำนวนล่าสุด **63 กิจกรรม / 84 จุดคำตอบ / 7 รูปแบบ**; ส่วนขยายเดิม 50 กิจกรรมคงอยู่ครบ. การมีรูปแบบนี้ในชีทอาจารย์เป็นข้อมูลที่ผู้ใช้แจ้งเพิ่มเติม; ยังไม่มีหน้าชีทที่ตรวจได้ในทะเบียนแหล่งข้อมูล.

เพิ่มล่าสุด 50 กิจกรรม รวม **62 กิจกรรม / 78 จุดคำตอบ**. จำนวนกิจกรรมใหม่ไม่นับช่องว่างในเรื่องเป็นกิจกรรมแยก: ดูภาพ 10, หาคำต่างกลุ่ม 10, ทายสถานที่ 10, ประกอบคำ 10, จัดหมวด 5, เรื่องสั้นทั้งเรื่อง 5. รอบใหม่ไม่เกิน 15 กิจกรรม เลือกกิจกรรมที่ยังไม่เคยพบก่อนกิจกรรมที่เคยทำ และเรียงกิจกรรมที่เลือกแล้วตามระดับความยาก. กิจกรรมจะถูกเลือกต่อเมื่อคำที่ต้องใช้และตัวลวงทุกคำมีหลักฐานเรียนแล้ว; คำ Lieblingsort, Lieblingsviertel และ Straßenfest ต้องเรียนรายการคำเพิ่มเติมก่อน.

คลังและกฎชนิดกิจกรรมอยู่ใน `src/lib/l13-vocabulary-challenge-bank.ts`; สถานะรอบและการอ่านข้อมูลเก่าอยู่ใน `src/lib/l13-vocabulary-challenge-state.ts`. รักษา ID และคำตอบครั้งแรกของ 15 จุดเดิม. ประวัติรุ่น 2 เก็บคิวรอบและประวัติรอบก่อน เพื่อให้ “ฝึกเพิ่ม” หมุนไปยังกิจกรรมใหม่แทนทำชุดเดิมซ้ำ. ข้อมูลอ้างอิงรายกิจกรรมอยู่ใน `l13-vocabulary-challenge-sources.json`; รัน `npm run audit:l13-vocabulary-challenge` เพื่อตรวจจำนวน ความครบของคำตอบ ภาพ และหลักฐานรูปแบบ. การแต่งโจทย์ใหม่ไม่อ้างว่าเฉลยผ่านการรับรองจากสำนักพิมพ์.

รายละเอียด 12 กิจกรรมรุ่นแรกต่อไปนี้คงไว้เป็นประวัติการออกแบบ; ขอบเขตและจำนวนล่าสุดเป็นไปตามส่วนขยายด้านบน.

ผลตรวจส่วนขยาย: `audit:l13-vocabulary-challenge` ยืนยันจำนวนใหม่ 50 รวม 62 กิจกรรมและ 78 จุดคำตอบ พร้อมภาพและหลักฐานรูปแบบครบ. `test:l13-vocabulary-challenge` ตรวจการอ่านรอบเดิม การคัดจากคำที่เรียนแล้ว การหมุนครบคลัง และการบันทึกประวัติ. `test:l13-vocabulary-challenge-browser` เล่นทั้ง 50 กิจกรรมใหม่ผ่านเว็บทดสอบจริง ตรวจร่างเรื่องสั้น การคืนคำและส่วนคำ เฉลย การฝึกเพิ่ม หน้าจอมือถือ และไม่พบข้อผิดพลาดหน้าเว็บหรือการบันทึก; คืนข้อมูลรอบทดสอบเดิมเมื่อจบ.

ปรับการแสดงเรื่องสั้น: `story-market`, `story-museum`, `story-playground`, `story-cafe` แสดงรวมเป็นบทความเดียวชื่อ `Ein Tag in der Stadt` และตรวจพร้อมกัน. คง ID และผลครั้งแรกเดิม พร้อมบันทึกร่างรายช่อง. ภาพประกอบเพิ่มจากไฟล์เดิม `public/images/lektion-13-city/stadt-places.webp` อยู่ข้างคลังคำที่กดมาเติมได้. ดังนั้น 15 จุดคำตอบแสดงเป็น 12 กิจกรรม ไม่แยกเนื้อเรื่องเป็นสี่หน้าต่อไป. ไม่มีการเพิ่มข้อความจากหนังสือ.

โจทย์แต่งใหม่ 15 ข้อใน `src/components/l13-vocabulary-challenge.tsx`: เรื่องสั้นเที่ยวเมือง 4 ช่องว่าง, หาคำต่างกลุ่ม 3 ข้อ, ดูภาพสถานที่ 4 ข้อ, และทายสถานที่จากประโยคบรรยาย 4 ข้อ. เฉลยอธิบายเหตุผลเป็นภาษาไทย. คำตอบและตัวเลือกทุกคำผูกกับ item ID บท 13 และต้องมีหลักฐานเรียนแล้วก่อนแสดงข้อ. ภาพใช้ไฟล์เมืองบท 13 ที่มีอยู่ในโปรเจกต์. เก็บผลใน lesson state แยกจากคลังพื้นฐานและคิวแนะนำ. ต้นแบบนี้ยังไม่ประเมินความชำนาญจากคะแนนรอบเดียว.

แรงบันดาลใจด้านรูปแบบมาจากภาพ Arbeitsbuch บท 13 ที่ผู้ใช้ส่งในวันที่ 24 October 2026 (หน้าในภาพพิมพ์เลข 6: เติมคำ, ตัดคำไม่เข้าพวก, จับคู่สถานที่กับภาพ, ปริศนาคำจากคำบรรยาย). ข้อความ โจทย์ คำอธิบาย และการเลือกภาพในชุดนี้เขียนใหม่จากคลังบทเรียนในโปรเจกต์; ไม่คัดบทอ่าน ภาพ แผนที่ หรือผังปริศนาจากหนังสือ. หมายเลขเล่มและไฟล์ต้นฉบับของภาพส่งมายังไม่ได้ยืนยัน จึงไม่อ้างว่าเป็นโจทย์ต้นฉบับหรือเฉลยสำนักพิมพ์.

- เลือกความหมาย วัดการจำความหมายของคำเยอรมัน ตัวเลือกไทยไม่ซ้ำและไม่ใช้คำพ้องเป็นตัวลวง
- เลือก Artikel วัดเพศของคำนามแยกจากความหมาย
- พิมพ์คำ วัดการนึกคำและสะกดโดยไม่เห็นรูปคำก่อนตอบ ไม่ต้องพิมพ์ Artikel คำนามต้องขึ้นต้นด้วยตัวใหญ่และคงเครื่องหมายกำกับเสียงตามรูปคำ

Geschäft/Laden และ Zoo/Tierpark ยอมรับเป็นคำตอบทดแทนในโจทย์พิมพ์ที่มีความหมายทับซ้อนกัน ไม่ใช้ความกำกวมนี้ตัดสินว่าผู้เรียนผิด เก็บรูป Tourist/Touristin และ Blogger/Bloggerin เป็นคำตอบที่ยอมรับทั้งสองรูปโดยไม่คัดชื่อแสดงผลเดิมที่มีคำซ้ำ

## การเลือกข้อและ UX

ตรวจขอบเขตสี Artikel เพิ่มเติม 24 October 2026: ทั้ง basic, daily, urban, culture, leisure, extra ใช้ ArticleLegend กลางแบบ sticky นอก iframe. Generator ส่ง `nounPresentation` และ palette กลางไปยัง HTML renderer เพื่อแสดงจุดหน้าคำนามในโจทย์ความหมายและเฉลย. ข้อเลือก Artikel ระบายสีทุกตัวเลือก der/die/das โดยไม่บอกสีของคำนามเป้าหมายก่อนตอบ. ข้อสะกดไม่แสดงคำเฉลยหรือสีของเฉลยก่อนตรวจ. คำพหูพจน์ใช้ metadata `pluralOnly` และสีเหลือง. การแก้เฉพาะ presentation ไม่เปลี่ยน target/subskill, ID, accepted answers หรือผลเก่า.

ใช้ `GUIDED_AND_PERSONALIZED_PRACTICE` และตัวฝึกเดียวกับไวยากรณ์ มีข้อเสนอให้ทำตัวฝึก React ใหม่ แต่เลือกขยาย HTML engine เดิมตามผลเปรียบเทียบและการตรวจแบบแยกกัน เพราะรักษา state, checkpoint, confidence และการบันทึกบัญชีเดิมได้โดยไม่เขียน controller ซ้ำ นำแนวคิดแยก learning item ID ออกจาก question ID และตัวกรองสิทธิ์ฝึกมาใช้ร่วมด้วย

หลักฐานว่าเรียนแล้วมาจาก image learned IDs ของบัญชีและ ItemExposure ในหมวดคำศัพท์บท 13 ห้ามสร้าง exposure จากการเปิดแบบฝึก ผู้ที่ยังไม่มีคำที่เรียนแล้วเห็นทางไปเรียนแทนโจทย์ ไม่มีการปลดล็อกคำเพียงเพราะเป็นบัญชีทดลอง

หลังเรียนจับคู่ภาพครบสามกลุ่ม ปุ่มทำแบบฝึกหัดเปิดข้อแรกทันที โดยปกติเป็น 15 ข้อจากสามกลุ่ม หากเคยเรียนคำเพิ่มเติมด้วย รอบจะรวมหัวข้อที่มีสิทธิ์ฝึก หัวข้อละไม่เกิน 5 ข้อ รวมได้สูงสุด 20 ข้อ เมื่อคลังของหัวข้อมีน้อยกว่า 5 ข้อจะใช้เท่าที่มี ไม่เพิ่มคำที่ยังไม่ได้เรียนเพื่อให้ครบจำนวน

ในรอบหัวข้อ 5 ข้อ จัดความหมาย 2 ข้อ Artikel 2 ข้อ แล้วพิมพ์ 1 ข้อเมื่อคลังรองรับ หัวข้อที่ไม่มี Artikel ใช้ข้อที่มีแทน เลือกคำให้หลากหลายและให้ความสำคัญกับข้อที่ยังไม่เคยทำ เมื่อครบหัวข้อแสดงจุดพักและไปหัวข้อถัดไปได้

หน้าเลือกหัวข้อใช้กลุ่มเดียวกับบทเรียน มีคำที่เรียนแล้วและปุ่มทำแบบฝึกหัด ไม่ต้องตั้งค่ารูปแบบหรือจำนวนข้อ ผู้เรียนเลือกคำตอบหรือพิมพ์ กดตรวจ ดูเฉลยและความหมาย ประเมินความมั่นใจ แล้วไปข้อต่อไป ไม่มี tooltip ที่เปิดคำแปลเฉลยก่อนตอบ หลังจบรอบมีฝึกเพิ่ม ทบทวนข้อผิด/ไม่มั่นใจ และหัวข้อถัดไปที่มีคำเรียนแล้ว

- Ground: ตรวจเส้นทางการเรียน ตัวฝึก คำแนะนำ registry และฐานข้อมูล
- Sketch/Agree: เปรียบเทียบขยาย engine เดิมกับสร้าง React ใหม่ เลือก engine เดิมและแยก scope ตามทักษะ
