แต่ละตัวอย่างมีสื่อของตนเอง ไม่ใช้ป้ายราคาหรือข้อมูลบุคคลหนึ่งครอบบทสนทนาต่างบริบทในหัวข้อเดียวกัน การตั้งคำตอบเรื่องความเห็น/ความถี่/การปฏิเสธต้องมีเจตนาหรือข้อมูลให้ชัด ถ้าประโยคสองแบบใช้แทนกันได้จริง จะไม่ใช้เป็นตัวลวงผิดของกันและกัน

การจัด L11-COMM-01 ใหม่ (8 พฤศจิกายน 2026) ใช้สามบัตรสอนโครงสร้าง: Aussage, W-Frage และ Ja-/Nein-Frage. เริ่มจาก `Ich arbeite.` → `Ich habe gearbeitet.` ก่อนแสดงหน้าที่/ตำแหน่งของกริยาช่วยที่ผันแล้วและ Partizip II; จากนั้นค่อยเทียบ `Wo hast du Deutsch gelernt?` และ `Habt ihr die Hausaufgaben gemacht?`. เสียงของแต่ละบัตรอ่าน Präsens แล้วตามด้วย Perfekt. ตัวอย่างสอนโครงสร้างนี้เป็นสื่อการเรียน ไม่ได้เพิ่ม scored target หรือเปลี่ยนโจทย์/ประวัติเดิม. คำบอกช่วงเวลาและลำดับอยู่ในหัวข้อ L11-COMM-02.

การจัด L11-COMM-02 ใหม่ (8 พฤศจิกายน 2026) ตั้งชื่อเป้าหมายว่า “บอกช่วงเวลาและลำดับในอดีต” และแยกคำอธิบายตามตัวอย่าง B: ช่วงเวลา `von … bis …`, จุดเริ่ม `ab`, และลำดับ `Danach` / `Dann`. หลักเดียวที่เชื่อมตัวอย่างคือคำบอกเวลา/ลำดับอยู่ต้นประโยค, กริยาที่ผันแล้วอยู่ตำแหน่งที่ 2, และ Partizip II ปิดท้ายแต่ละประโยค. ตัดคำอธิบายโครงสร้างของ A ออกเพราะสอนรูปคำถามแล้วในหัวข้อก่อน; ไม่เปลี่ยน scored target หรือประวัติเดิม.

ใช้บทสัมภาษณ์/แบบสำรวจจากชีทมาเป็นสถานการณ์สั้น ไม่ทำตารางกริยาให้เป็นคำถามหมวดประโยคทุกข้อ ใช้โครงสร้างและคำอธิบายเท่าที่ช่วยสื่อสาร การแสดงคำตอบทั้งประโยคอยู่ในตัวอย่างและหลังตรวจ; ข้อฟังไม่มีข้อความเฉลยอยู่บนแผงประกอบ

## บท 5 และการป้องกันโจทย์เฉลยตัวเอง

ร่างเก่าเคยแสดงคำ Schirm แล้วให้เรียงตัวสะกด และแสดงอีเมลก่อนตอบ งานนั้นเป็นการคัดตามแบบ จึงไม่เปิดเป็นงานสะกดอิสระ รุ่นนี้สอนการถามสะกดในตัวอย่าง แต่ข้อประเมินใช้เสียงตัวอักษรโดยซ่อนคำ แล้วพิมพ์คำตอบ ส่วนข้ออีเมลใช้ที่อยู่สมมติใหม่จากเสียง ผลเก็บเป็น `word_spelling_listening` และ `email_listening` แยกกัน มีตัวอย่างก่อนหน้า/เสียงซ้ำและ Artikel ที่ให้เป็นตัวช่วย จึงยังไม่อ้างว่าเป็น independent mastery

คำนามเดี่ยวใช้ NounText/NounPrefix และ ArticleLegend ร่วมกัน เช่น der Schirm ในเฉลยและ der ที่ให้ข้างช่องสะกด หรือ der Salat/der Kuchen ในโปรไฟล์การอ่าน คง Akkusativ/คำย่อ/กรณีในประโยคจริง ไม่เติม nominative Artikel เข้าไปในประโยคโดยกลไก

## การเลือกฝึกต่อและช่องว่างที่ยังไม่ implement

คิวนี้เป็น guided Learn สำหรับการพบเนื้อหาครั้งแรก ไม่ใช่ active adaptive selection ข้อเสนอสำหรับการต่อ Practice ต้องใช้ผลแยก subskill:

- เข้าใจความหมายแต่เรียงผิด: เลือกโครงสร้างเดียวกันในสถานการณ์ใหม่ พร้อมลดจำนวนคำก่อน ไม่ให้ท่องความหมายเดิมซ้ำ
- อ่านกระดานถูกแต่ฟังผิด: เลือกเสียงข้อมูลใหม่ในหมวดเดียวกัน ไม่ถือว่าการอ่านพิสูจน์การฟัง
- สับสน nein/doch หรือชวน/ปฏิเสธ: เปลี่ยนข้อเท็จจริงและเจตนา แล้ววัดหน้าที่เดิม ไม่วนเฉพาะข้อที่จำได้แล้ว
- พิมพ์อีเมลตกเครื่องหมาย: แยกผลนี้จากความเข้าใจการถามอีเมล ใช้ข้อความใหม่และข้อมูลสมมติ
- ก่อนลดตัวช่วย ทดลองใช้คำตอบแรกถูกอย่างน้อยสองสถานการณ์อิสระต่างรอบโดยไม่เปิดตัวช่วยเฉลย เป็นค่าเสนอเพื่อทดสอบ ยังไม่ใช้ตัดสินผู้เรียนจริงหรือเรียกว่า mastery

ส่วน aggregation เป็น learner state, นโยบายเลือกโจทย์ถัดไป, การเชื่อมคำแนะนำร่วมและ Practice eligibility/server validation สำหรับ target ใหม่ ยังไม่ได้ implement งานต่อไปต้องใช้ shared `learner_practice_sessions` / PracticeAccountSync / server question registry ไม่เอา Learn checkpoint ไปแทน Practice store
