# เงื่อนไขเปิดใช้กับบัญชีทั่วไป

สถานะปรับล่าสุด 9 พฤศจิกายน: รายการด้านล่างเป็นผลตรวจตอนเริ่มงาน ปัจจุบันปลด Learn gates L01–14 แล้ว และสร้าง L15–18 ครบ 12 หมวดพร้อม shared Practice banks ดูผลตรวจและสิ่งที่ยังรอใน RELEASE_EXECUTION.md ไม่ถือว่าระบบจริง deploy แล้ว
ข้อกำหนดผู้ใช้ 9 พฤศจิกายน 2026: เมื่องานบทเรียนที่แก้หรือสร้างเสร็จ ต้องใช้งานกับบัญชีผู้ใช้ทั่วไปได้ด้วย การเปิดเฉพาะบัญชี tester เป็นขั้นตรวจงาน ไม่ใช่สถานะส่งมอบขั้นใช้งานจริง

ชุด L15–L18 นี้กำหนดผู้ใช้เป้าหมายเป็นผู้ใช้ที่เข้าสู่ระบบทั่วไป แต่ยังเป็นข้อมูลเตรียมสร้าง หน้าเรียน สื่อ grader และ integration ยังไม่เสร็จ จึงยังไม่เปิดข้อมูลร่างให้ผู้เรียน

## ต้องทำในขั้นสร้างและเปิดจริง

1. Register คำศัพท์/เป้าหมายภาษาและคำถามที่ตรวจแล้ว ใช้ ID เดิมเมื่อเป็นเนื้อหาเดิม ไม่แทนที่คำตอบ/คิว/สถานะของผู้เรียนเก่าโดยเงียบ ๆ
2. ให้เส้นทางหลักของบัญชีทั่วไปเข้าถึง renderer ที่แก้แล้ว ไม่พึ่งรายชื่ออีเมล tester หรือ `isTestWorkspaceUser` เพียงอย่างเดียว
3. จัด migration ให้ server รับ lesson-state keys, bank และ question IDs ที่ใช้จริง โดยคง RLS แยกบัญชี ห้ามแก้ด้วยการใช้ Practice ของผู้ที่ยังไม่เคยเรียนหรือสร้าง exposure ปลอม
4. เชื่อมข้อมูล Learn, first answers, helper usage, drafts และ resume กับบัญชีจริงตามชนิดของหลักฐาน Practice ประโยคใช้ shared session store ไม่เพิ่ม lesson-state practice store แยก
5. ทดสอบบัญชีทั่วไปแยกจาก tester ให้การเห็นเนื้อหา การเรียนก่อนฝึก บันทึกผล ปิด/เปิดหน้าใหม่ สลับบัญชี และ recommendation ทำงานจริง
6. ทดสอบรอบเก่าที่ค้างอยู่ด้วย schema/รุ่นเดิม ไม่ย้ายผลจาก prototype มาเป็นความสามารถของผู้ใช้ทั่วไป
7. เปิด feature และ apply migration ตาม deployment จริงเมื่อพร้อม ระบุแยกว่าพร้อมในโค้ด ทดสอบในเครื่องแล้ว หรือเปิดบนระบบจริงแล้ว ห้ามรายงานว่าเปิดแล้วเพียงเพราะลบเงื่อนไขในหน้าเว็บ

## ส่วนเดิมบท 1–14 ที่ตรวจเส้นทางไว้

- `trainer.tsx` ยังเลือกหน้า L01/L02 และ shared L03–L12 แบบใหม่ด้วยเงื่อนไข tester
- `l13-phrase-pages.tsx` ยังจำกัด shared Learn แบบใหม่เฉพาะ tester
- `l14-phrase-learning.tsx` ยังจำกัด supplemental models/annotations/observations ด้วย `enhanced = isTestWorkspaceUser(user)`
- lesson-state keys ของส่วนนี้เพิ่มให้ local test adapter แล้ว ยังไม่มี hosted migration สำหรับ discovery L01–L13 และ guidance/observations L14 ในงานเดิม
- การปลด gate ต้องตรวจ canonical exposure และ after-Learn Practice ของแต่ละ renderer ด้วย โดยเฉพาะ L01 ไม่อนุมานว่าแบบ discovery checkpoint เท่ากับการเรียน catalog item ทุกตัว
- คำสั่งเปิดบัญชีทั่วไปเป็นข้อกำหนดการส่งมอบถัดไป ส่วนที่ยังไม่เปิดต้องรายงานตรง ๆ ไม่ใช้ข้อความว่าเผยแพร่แล้ว

การตรวจไฟล์ชุดเตรียม L15–L18 ไม่ได้ทำให้ gate หรือฐานข้อมูลของส่วนเดิมเปลี่ยน ไม่มีการ deploy หรือ apply schema ของระบบจริงในขั้นเตรียมเนื้อหานี้
