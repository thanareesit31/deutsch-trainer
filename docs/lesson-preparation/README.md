สถานะ 9 พฤศจิกายน 2026: เชื่อม runtime ครบ 12 หมวดแล้ว ดูสถานะส่งมอบปัจจุบันใน RELEASE_EXECUTION.md ข้อมูล JSON ด้านล่างเป็นต้นทางการประพันธ์ที่เก็บแยกจากชุด runtime ซึ่งสร้างด้วย build-a13-release.py การเผยแพร่ระบบจริงยังต้องตรวจ migration และ deployment จริง

| 17 | 22 | werden, wollen, mit/ohne | แผนอาชีพ แผนส่วนตัว ระดับความต้องการ และเงื่อนไขของแผน |

อ่าน [เนื้อหาและลำดับการสอน](L15_L18_CONTENT_PLAN.md) เพื่อดูคำศัพท์ทั้งหมด ตัวอย่าง และบทสนทนา 32 ชุด อ่าน [แผนการวัดผลและการเชื่อมระบบ](L15_L18_ASSESSMENT_PLAN.md) ก่อนสร้างกิจกรรมที่คิดคะแนน

## ไฟล์สำหรับสร้างและตรวจ

- `l15-content.json` ถึง `l18-content.json`: learner copy, 97 รายการคำ/วลี, บัตรไวยากรณ์ 16 บัตร, บทพูด 64 เป้าหมาย และหน่วยกิจกรรมร่าง 372 หน่วย พร้อมคำแปลและ feedback
- `grammar-feedback-authoring.json`: ต้นทางข้อความเฉลยไวยากรณ์ 35 ข้อที่เก็บคำตอบเดิมไว้ แยกจากรหัสฉบับเตรียม; อีก 4 ข้อวินิจฉัยสร้างใน generator
- `l15-l18-assessment-bindings.json`: target/subskill, ความยากพร้อมเหตุผล ตัวช่วย และสิ่งที่ต้องเรียนก่อน; ไม่เป็นประวัติผู้เรียน
- `l15-l18-asset-manifest.json`: script เสียงรายคำ ตัวอย่าง ไวยากรณ์ เฉลย และ A/B รวมทั้งคำขอภาพ/กระดานข้อมูล ไฟล์เสียงใหม่ยังไม่ได้สร้าง ภาพเดิมที่พบยังต้องตรวจความหมาย
- `l15-l18-source-review.json`: หน้าที่ดูจาก cached renders, checksum, ข้อมูลเดิม, ข้อกำกวม และจุดที่ยังต้องตรวจ เก็บแยกจากข้อความผู้เรียน
- `manifest.json`: จำนวน ขอบเขต readiness และ hash ของต้นแบบไวยากรณ์ที่ไม่ได้แก้
- [ข้อกำหนดการเปิดบัญชีทั่วไป](GENERAL_ACCOUNT_RELEASE.md): เงื่อนไขส่งงานเมื่อสร้างและเชื่อมระบบเสร็จ

คำศัพท์ L15 รักษารหัสเดิมทั้ง 24 รายการ ไวยากรณ์ต้นแบบ 35 ข้อไม่ได้ถูกเขียนทับ ฉบับ PREP3 เพิ่มบริบท/คำกริยาต้นทาง แก้การแสดงข้อเรียงคำ และแยกมิติที่ต้องวัดให้ชัด มี probe อีก 4 ข้อเพื่อแยกเจ้าของ/ท้ายคำ เวลา/รูป Dativ และความหมาย mit/ohne ออกจากการผัน Case

นี่เป็นชุดเลือกเนื้อหาสำหรับสร้าง ไม่ใช่การถอดแบบฝึกหัดทุกข้อจากหนังสือ หน่วยกิจกรรมเป็น candidate pool ไม่ใช่คิวที่บังคับให้ผู้เรียนทุกคนทำจนครบ

## สร้างซ้ำและตรวจโดยไม่แตะข้อมูลผู้เรียน

```sh
python3 scripts/exercise-mapping/prepare-l15-l18-content.py
python3 scripts/exercise-mapping/validate-l15-l18-preparation.py
```

Generator อ่าน seed และ bank เดิม แล้วเขียนเฉพาะไฟล์ในโฟลเดอร์เตรียมนี้ ต้องมี cached source renders ในเครื่องเมื่อสร้าง metadata แหล่งซ้ำ Validator อ่าน artifacts และตรวจได้โดยไม่ต้องมีภาพ cached อยู่ในเครื่องนั้น

ผลตรวจครอบคลุม target/response bindings, Artikel/จำนวน, การไม่แสดง Artikel ในโจทย์ที่ถาม Artikel, ตัวช่วย Artikel ในการสะกด, ชุดคำเรียงที่ยังไม่เรียงถูกไว้ก่อน, คำตอบไวยากรณ์เดิม, ข้อความเฉลยที่ตรงกับโจทย์เติมแล้ว, เสียง A/B ที่เป็น script ตรงข้อความ และการไม่ปน source metadata ลงใน learner payload ประโยคตัวอย่างและเฉลย 216 แถวสร้างข้อความเยอรมันเดิมได้ครบ

ก่อนเผยแพร่ยังต้องตรวจ morphology/คำตอบทางเลือก จัดทำและตรวจสื่อ สร้าง renderer เชื่อมบัญชีและ selector และทดสอบบัญชีทั่วไปกับการคืนประวัติจริง ไม่มีการยืนยันว่า UI หรือ adaptive selection เปิดใช้งานแล้วจากการตรวจไฟล์ชุดนี้
