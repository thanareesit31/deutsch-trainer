# หลักการเรียนและฝึกจากหลักฐานรายบุคคล

รหัสมาตรฐาน: `TARGET_AND_SUBSKILL_ADAPTIVE_LEARNING`
เริ่มใช้เป็นข้อกำหนด: 24 ตุลาคม 2026

หลักการนี้ใช้กับทุกบทและทุกทักษะ เมื่อสร้างหรือแก้บทเรียน เนื้อหา หรือแบบฝึกหัด ให้ออกแบบข้อมูลสำหรับการวิเคราะห์ผู้เรียนและการเลือกฝึกครั้งต่อไปตั้งแต่ต้น. อ่านร่วมกับ `PRODUCT_BASELINE.md` และ `PRACTICE_FLOW_STANDARD.md`. การประกาศมาตรฐานไม่ได้หมายความว่าระบบเดิมทุกส่วนเชื่อมการวิเคราะห์นี้แล้ว.

## เป้าหมายของผลิตภัณฑ์

ระบบต้องรู้จากหลักฐานว่าผู้เรียนแต่ละคนทำอะไรได้แล้ว ยังติดตรงไหน และควรฝึกอะไรต่อด้วยความช่วยเหลือระดับใด. การคละโจทย์หรือเรียงรูปแบบง่ายไปยากเป็นเพียงส่วนหนึ่งของการจัดรอบ; การปรับระดับต้องอิงผลของเป้าหมายและทักษะย่อยของผู้เรียนคนนั้น.

## หน่วยที่ต้องติดตาม

ใช้ความสัมพันธ์ `ผู้เรียน → เป้าหมายการเรียน → ทักษะย่อย → หลักฐานคำตอบ` เป็นหน่วยวิเคราะห์.

- คำศัพท์: คำแต่ละคำมี ID คงที่ แยกจำความหมาย, Artikel, สะกด และเลือกใช้ตามบริบท.
- ประโยคและสำนวน: ติดตามสำนวนหรือหน้าที่การสื่อสาร แยกเข้าใจความหมาย, เลือกคำตอบในบทสนทนา, ลำดับคำ และสร้างคำถามหรือคำตอบ.
- ไวยากรณ์: ติดตามกฎหรือโครงสร้างเฉพาะ แยกรู้รูป, เลือกรูปในบริบท และสร้างรูปหรือประโยคเอง. หากใช้คำหลายคำวัดกฎเดียวกัน ให้มี ID กฎที่เชื่อมกันอย่างชัดเจน.
- อ่านและฟัง: ติดตามเป้าหมายความเข้าใจ เช่น ใจความสำคัญหรือรายละเอียด โดยผูกกับหน่วยบทอ่านหรือเสียงและบริบทที่ตรวจได้. การตอบผิดไม่ยืนยันว่าผู้เรียนไม่รู้คำทุกคำในบทอ่าน.
- เขียนและพูด: ใช้เกณฑ์รายด้านและหลักฐานที่ประเมินได้จริง. คำตอบเปิดหรือการให้คะแนนที่ยังไม่แน่นอนต้องบันทึกสถานะนั้น ไม่สร้างผลถูกผิดหรือความชำนาญขึ้นเอง.

ID ของโจทย์ รูปแบบกิจกรรม และ ID ของเป้าหมายต้องแยกกัน. เปลี่ยนโจทย์หรือรูปแบบแล้วยังเชื่อมกับเป้าหมายเดิมได้. อย่ารวมเป้าหมายต่างบทหรือคำพ้องโดยอัตโนมัติโดยไม่มีการตรวจความหมาย.

## ออกแบบบทเรียนให้เชื่อมหลักฐาน

ก่อนเพิ่มเนื้อหา ให้ระบุสิ่งที่จะสอนจริง เป้าหมายและทักษะย่อยที่คาดหวัง ตัวอย่างที่ผู้เรียนได้รับ และหลักฐานว่าได้พบหรือเรียนแล้ว. ผูกกิจกรรม Learn และโจทย์ Practice ด้วยเป้าหมายเดียวกัน.

การเปิดหน้า การกดเรียนแล้ว หรือการเห็นเฉลยเป็นหลักฐานการพบเนื้อหา ไม่ใช่หลักฐานว่าทำได้ด้วยตนเอง. ปุ่มอำนวยความสะดวกของบัญชีทดลองต้องไม่สร้างคะแนนความสามารถให้บัญชีทั่วไป.

## ข้อมูลขั้นต่ำของโจทย์และหน่วยคำตอบ

ให้คลังในขอบเขตที่แก้มีข้อมูลต่อไปนี้หรือมีการแมปไปยังโครงสร้างเดิมอย่างชัดเจน. ไม่ต้องเปลี่ยนชื่อ field หรือสร้างระบบเก็บข้อมูลซ้ำเมื่อของเดิมรองรับแล้ว.

| ข้อมูล | ความหมาย |
| --- | --- |
| task ID และ version | แยกโจทย์และรุ่นที่คำตอบอ้างถึง |
| activity ID และ response ID | แยกหน้ากิจกรรมออกจากช่องคำตอบหรือคู่จับคู่ |
| target ID และ subskill | ระบุว่าแต่ละคำตอบวัดเป้าหมายและทักษะใด |
| required learning IDs | เนื้อหาเป้าหมาย บริบท และตัวเลือกที่ต้องมีหลักฐานเรียนแล้ว |
| difficulty และเหตุผล | ระดับความต้องการของงาน ไม่ใช่เพียงชื่อรูปแบบ |
| assistance | คำชี้นำ ตัวอักษรตั้งต้น คลังคำ ตัวเลือก คำแปล หรือสิ่งช่วยอื่นที่มีให้ |
| scoring และ accepted answers | วิธีตรวจ คำตอบที่รับได้ และขอบเขตการให้คะแนน |
| error categories | ความผิดที่โจทย์แยกได้จริง เช่น ความหมาย Artikel การสะกดหรือลำดับคำ |
| evidence bindings | ผลช่องใดนำไปปรับหลักฐานของ target/subskill ใด |
| progression links | ตัวเลือกที่ง่ายลง มีตัวช่วยมากขึ้น หรือยากขึ้นในทักษะเดียวกัน |

เรื่องสั้นหลายช่อง ปริศนาคำศัพท์หลายแถว และจับคู่หลายคู่ต้องบันทึกผลรายหน่วยคำตอบ. จำนวนหน้ากิจกรรมไม่เท่ากับจำนวนหลักฐาน. ถ้าคำตอบเดียวพึ่งหลายเป้าหมายจนแยกสาเหตุไม่ได้ ให้บันทึกว่าแยกไม่ได้ ห้ามหักคะแนนทุกเป้าหมายพร้อมกัน.

เก็บแหล่งอ้างอิงและเหตุผลการดัดแปลงใน metadata ภายในตาม AGENTS.md.

## หลักฐานที่ต้องเก็บจากการฝึก

เก็บต่อบัญชี: session/event ID ที่ป้องกันการนับซ้ำ, task version, response ID, target/subskill bindings, คำตอบครั้งแรก, ผลตรวจ, เวลา, ระดับโจทย์, ตัวช่วยที่มีและที่ใช้, การดูคำแปล, และสถานะตรวจหรือคะแนนที่ยังไม่แน่นอน. บันทึกความมั่นใจได้เมื่อมีการถาม แต่ไม่ใช้แทนความถูกต้อง. เวลาตอบอาจเป็นข้อมูลประกอบเมื่อวัดได้อย่างเหมาะสม ไม่บังคับใช้เป็นตัวตัดสินความสามารถ.

Practice does not ask for confidence or show easy/thought/guess or not-sure buttons. Checked answers complete immediately: answer, read feedback, continue. New confidence remains unknown, never easy or mastery. Preserve historical ratings and first answers for compatibility. Resume old pending answers at feedback without answering again. Use first-answer correctness, assistance and independent evidence across formats/days to choose practice. Open responses retain their assessment criteria; do not invent binary grading.

รักษาคำตอบครั้งแรกและการแก้หลังเห็นเฉลยให้แยกกัน. การส่งซ้ำ การรีเฟรช หรือการเปิดอุปกรณ์อื่นต้องไม่สร้างหลักฐานอิสระเพิ่ม. คำตอบที่มีตัวช่วยไม่เท่ากับคำตอบที่ทำได้เอง. ข้อมูลเก่าที่ไม่ได้เก็บตัวช่วยมีสถานะไม่ทราบ.

เก็บผลเข้าบัญชีและมีทางกู้คืนข้อมูลรอส่ง. การจัดเก็บอย่างเดียวไม่ได้ยืนยันว่ามีการวิเคราะห์หรือปรับระดับแล้ว. การตรวจผลและความเป็นเจ้าของข้อมูลที่ใช้แนะนำจริงต้องอยู่ในเส้นทางที่เชื่อถือได้และตรวจย้อนหลังได้.

## ระดับความยากและการวิเคราะห์

ระดับง่าย กลาง ยากต้องนิยามต่อทักษะและงาน เช่น การนึกคำเองยากกว่าการจำแนกจากตัวเลือกเมื่อวัดการสะกด. รูปแบบเดียวกันมีได้หลายระดับ และรูปแบบต่างกันไม่จำเป็นต้องเทียบความยากกันโดยตรง.

แยกความยากของภาษา ความซับซ้อนของบริบท ภาระการจำ และความซับซ้อนของวิธีตอบ. ความสับสนจาก UI หรือโจทย์กำกวมเป็นข้อผิดพลาดของกิจกรรม ไม่ใช่หลักฐานว่าผู้เรียนอ่อน.

ตัวอย่างคำ `Markt`:

| หลักฐาน | สิ่งที่สรุปได้ | การฝึกที่เหมาะสม |
| --- | --- | --- |
| เลือกความหมายจากภาพยังผิด | ต้องตรวจความหมายเพิ่ม | คำอธิบายสั้น ภาพชัด ตัวเลือกที่แยกกันได้ |
| เลือกความหมายได้หลายครั้ง | มีหลักฐานด้านการจำความหมาย | บริบทใหม่หรือการใช้คำ โดยยังไม่อ้างว่าสะกดได้ |
| เข้าใจความหมายแต่สะกดผิด | ต้องฝึกสะกด | ช่วยด้วยส่วนคำหรือตัวอักษรตั้งต้น แล้วค่อยลดตัวช่วย |
| สะกดเองได้ในรอบที่เว้นเวลาและบริบทต่างกัน | หลักฐานด้านการผลิตคำแข็งแรงขึ้น | งานสะกดที่ใช้ตัวช่วยน้อยลง และทบทวนตามเวลา |

อย่าประกาศว่าเก่งจากคำตอบถูกครั้งเดียวหรือจำโจทย์เดิมได้. เมื่อยังมีข้อมูลน้อย ให้ใช้สถานะหลักฐานยังไม่พอและโจทย์สำรวจที่เหมาะสม. นโยบายเลื่อนระดับ ลดตัวช่วย ทบทวนหลังเว้นเวลา และจำนวนหลักฐานต้องมีค่าตั้งต้นที่อธิบายได้ มี version และตรวจได้ในโค้ดเมื่อพัฒนา; ตัวเลขทดลองไม่ใช่เกณฑ์รับรองความชำนาญ.

## เลือกกิจกรรมครั้งต่อไป

1. กลับไปทำรอบที่ค้างก่อน โดยรักษาคิวและร่างเดิม.
2. สำหรับรอบใหม่ เลือกเฉพาะเนื้อหาที่มีสิทธิ์ฝึกและมีโจทย์ที่วัดทักษะนั้นจริง.
3. ดูหลักฐานของ target/subskill ก่อนเลือกระดับและตัวช่วย. ประเมินสิ่งที่ยังไม่รู้แยกจากสิ่งที่มีหลักฐานว่าต้องทบทวน.
4. ให้การฝึกแก้จุดที่ติดอยู่ ผสมการทบทวนตามเวลา งานสำรวจ และสิ่งที่ทำได้แล้วในสัดส่วนตามนโยบาย. ไม่สุ่มรูปแบบทั้งหมดโดยไม่ดูความสามารถ.
5. เมื่อทักษะหนึ่งดีขึ้น เลือกงานที่ท้าทายขึ้นหรือลดตัวช่วยในทักษะนั้น. ถ้ายังผิด ให้ช่วยหรือลดระดับภายในทักษะเดิมและอาจพาไปทบทวนบทอธิบายที่ตรงจุด.
6. คละเฉพาะผู้สมัครที่เหมาะสมและให้ความหลากหลายของบริบท. ไม่ให้จำนวนข้อบังคับสร้างคำถามซ้ำหรือใช้เป้าหมายที่ยังไม่เรียน.

บันทึกเหตุผลการเลือกในรูปที่ตรวจได้ เช่น target, subskill, สรุปหลักฐานที่ใช้, ระดับ/ตัวช่วยที่เลือก และ policy version. หน้าแรกและหน้า Practice ต้องใช้คำแนะนำจากตรรกะร่วมกันเมื่อเชื่อมระบบจริง ไม่มีกฎวิเคราะห์ที่ขัดกันในแต่ละหน้า.

## ใช้กับงานแก้ไขต่อเนื่อง

ก่อนแก้ ตรวจแผนเป้าหมายและข้อมูลที่วัดอยู่แล้ว. เมื่อเพิ่มรูปแบบ เพิ่ม target/subskill bindings และเส้นทางตัวช่วยของรูปแบบใหม่พร้อมกัน. เมื่อแก้คำตอบหรือความหมาย ให้กำหนด version/การอ่านผลเก่าอย่างเหมาะสมและรักษาคำตอบเดิม.

งานแก้เฉพาะหน้าตาต้องรักษา ID, การให้คะแนน และหลักฐานเดิม และตรวจว่า UI ไม่ให้คำตอบรั่วหรือสร้างความผิดที่ไม่ใช่ทักษะที่วัด. ไม่ต้องขยายทั้งหลักสูตรทุกครั้งเพียงเพราะแก้เลย์เอาต์.

ก่อนรายงานงาน ให้แยกสถานะสี่ส่วน: ออกแบบข้อมูลแล้ว, เก็บผลจริงแล้ว, ใช้ผลเลือกโจทย์จริงแล้ว, และเปิดใช้งานจริงในขอบเขตใด. การมี difficulty, subskill หรือประวัติคะแนนยังไม่เท่ากับปรับระดับรายบุคคล.

## ขอบเขต implementation ที่ทราบ ณ 24 ตุลาคม 2026

- `src/lib/learning.ts` มี exposure, evidence dimensions และโครงสร้างประวัติเดิม. `KnowledgeState` เป็นยอดรวมราย item; ห้ามถือว่าโครงสร้างนี้เพียงอย่างเดียวทำ adaptive progression ราย target/subskill ครบแล้ว.
- `src/lib/practice-planner.ts` มีคำแนะนำจากประวัติของคลังที่เปิดใช้. ต้องตรวจ data flow ของแต่ละ scope ก่อนอ้างว่ารองรับระดับความสามารถเฉพาะทักษะ.
- `src/lib/l13-vocabulary-challenge-bank.ts` และ `l13-vocabulary-challenge-state.ts` มีเป้าหมายที่ต้องเรียน ระดับคงที่ ผลรายคำตอบ และคิวจากประวัติกิจกรรม. ยังไม่มีโมเดลความสามารถแยกรายคำ/ทักษะย่อยที่เลือกตัวช่วยและระดับตามหลักฐาน. การขยายคลังอย่างเดียวไม่ปิดช่องว่างนี้.
- เส้นทางบทหรือทักษะอื่นต้องตรวจจากโค้ดและข้อมูลจริง. งานบันทึกมาตรฐานนี้ยังไม่ได้ย้ายคลังเดิมทั้งหมดหรือเปิดระบบ adaptive ส่วนกลาง.

ใช้ `.agents/skills/design-adaptive-learning/SKILL.md` ทุกครั้งที่สร้างหรือแก้เนื้อหาบทเรียนและแบบฝึกหัด. บันทึกแผนและช่องว่างของ scope ที่แก้ตาม template ในสกิล เพื่อให้งานถัดไปต่อได้โดยไม่ตีความเริ่มใหม่.

## Noun presentation and assessment

Teach and display German nouns together with their Artikel and the shared gender dot across all lessons and practice formats, including meaning and spelling.
