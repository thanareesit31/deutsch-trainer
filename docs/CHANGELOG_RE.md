# Requirement & Experience Changelog

## 2026-10-07 — ปุ่มออกจากระบบที่มองเห็นได้ทุกขนาดจอ

- **What changed:** ย้ายปุ่มออกจากระบบจากล่าง sidebar ไปด้านขวาบนทุกหน้า เพิ่มไอคอน สถานะรอ และข้อความเมื่อออกจากระบบไม่สำเร็จ; จอมือถือซ่อนป้ายระดับเพื่อให้ปุ่มมีพื้นที่
- **Why:** ปุ่มเดิมตกขอบจอได้ ทำให้ผู้เรียนหา logout ไม่พบ
- **Impact:** ใช้ Supabase signOut เดิม กลับหน้าล็อกอินเมื่อสำเร็จ ไม่ลบประวัติการเรียน; ป้องกันกดซ้ำและรอการบันทึก Learning History ที่กำลังดำเนินการ ไม่มี deploy ในงานนี้

## 2026-10-07 — เรียกข้อมูลพื้นที่ทดสอบผ่าน origin เดียวกับเว็บ

- **What changed:** ให้เบราว์เซอร์เรียก Auth/REST ทดสอบผ่าน `/__test-db` ของเว็บ โดย Next.js ส่งต่อไปฐานข้อมูลบนเครื่อง
- **Why:** แก้จุดเสี่ยงในการโหลดบทเรียนจาก `localhost` ไป `127.0.0.1` คนละพอร์ต ซึ่งขึ้นกับข้อจำกัดเบราว์เซอร์
- **Impact:** เปลี่ยนเฉพาะพื้นที่ทดสอบบนเครื่อง; คงฐานข้อมูลแยก บัญชีทดสอบ และการเชื่อมต่อ Supabase ของเว็บปกติ

## 2026-10-07 — พื้นที่ทดสอบและบัญชีทดสอบแยกจากข้อมูลจริง

- **What changed:** เพิ่ม `npm run dev:test` เปิดเว็บพอร์ต 3002 กับฐานข้อมูล PGlite แยกบนเครื่อง พร้อมบัญชีทดสอบสองบัญชีและแถบระบุพื้นที่; เริ่มประวัติว่างทุกครั้งที่เปิดคำสั่ง แต่ยัง resume ระหว่างรอบได้
- **Why:** ให้ผู้พัฒนาทดลองบทเรียนใหม่หลังแก้บัคโดยไม่สะสมประวัติในบัญชีหลักหรือใช้ปุ่มเรียนซ้ำเพื่อเทส
- **Impact:** ไม่เพิ่มปุ่มรีเซตในหน้าผู้เรียน ไม่เปลี่ยนกติกาบทเรียน/Practice/Progress หรือ runtime production; ข้อมูลทดสอบถูกทิ้งเมื่อปิดพื้นที่ Auth/REST ท้องถิ่นเป็นการจำลอง ส่วน SQL/RLS ใช้ migrations จริง ไม่ใช่ผลยืนยันบริการ hosted Supabase

## 2026-10-07 — ย้ายสถานะบทเรียนไป Supabase แยกตามบัญชี

- **What changed:** ย้ายสถานะ Alphabet, คำศัพท์จับคู่ภาพ และกระดาน/ตำแหน่ง/รอบเรียนซ้ำของ Verben ไปตาราง `learner_lesson_states` พร้อม RLS; กู้คืนก่อนเปิดกิจกรรมและล้างสถานะในหน่วยความจำเมื่อเปลี่ยนบัญชี
- **Why:** ป้องกันข้อมูลบทเรียนปะปนระหว่างบัญชีในเบราว์เซอร์เดียวกัน และให้เรียนต่อข้ามอุปกรณ์ได้
- **Impact:** คงกติกาการเรียน การปลดล็อก ปุ่มเรียนซ้ำ การตรวจคู่กริยา และ Practice/Progress เดิม; ต้องใช้ migration `20261007000000_learner_lesson_states.sql` ข้อมูล prototype ย้ายเฉพาะบัญชีเจ้าของที่ตรวจจาก session และกำหนดผ่าน `NEXT_PUBLIC_LEGACY_LESSON_OWNER_ID`; ไม่เขียนทับข้อมูล cloud ที่มีแล้ว และลบ legacy เฉพาะเมื่อยืนยันว่าบันทึกแล้ว รายการที่ส่งไม่สำเร็จเก็บรอส่งแยกบัญชีพร้อมปุ่มลองอีกครั้ง

## 2026-10-05 — ไปต่อเปิด Introduction ของกริยาถัดไปเสมอ

- **What changed:** ปุ่ม “ไปต่อ” หลังจบกริยาเปิดหน้า Introduction ของกริยาถัดไป แม้ผู้เรียนเคยเรียนกริยานั้นแล้ว
- **Why:** ป้องกันการข้าม Introduction ไปยังกระดานผันเดิม เช่น จาก heißen ไป lernen
- **Impact:** แก้ navigation เฉพาะ flow Verben Lektion 1; การเปิดแท็บกริยาที่เรียนไว้ยัง resume หน้าค้างเดิม

## 2026-10-05 — จัดปุ่มใน flow กริยาไว้ตรงกลาง

- **What changed:** จัดกลุ่มปุ่มใต้กระดานจับคู่ไว้กึ่งกลาง เปลี่ยนข้อความปุ่มไปกริยาถัดไปเป็น “ไปต่อ” และปรับ “เรียนการผัน” ให้กว้างพอดีกับข้อความพร้อมจัดกึ่งกลาง
- **Why:** ลดความกว้างของปุ่มและให้ตำแหน่ง action สอดคล้องกับที่ผู้ใช้ต้องการ
- **Impact:** ปรับเฉพาะปุ่มใน Grammatik → Verben Lektion 1

## 2026-10-05 — จัดตัวอย่าง Introduction ของ sein เป็นแถว

- **What changed:** วางตัวอย่างทั้ง 3 ชุดของ sein เรียงในแถวเดียวกัน โดยให้คำแปลไทยอยู่ใต้ประโยคเยอรมันของแต่ละชุด; พื้นที่แคบให้ตัดแถวได้
- **Why:** ลดความสูงของหน้า Introduction โดยเฉพาะตัวอย่างหลายประโยคของ sein
- **Impact:** ปรับเฉพาะการจัดวางตัวอย่างใน Grammatik → Verben Lektion 1

## 2026-10-05 — ปุ่มย้อนกลับจากตารางสรุป

- **What changed:** ปุ่ม “ย้อนกลับ” ใต้ตารางสรุปเปิดกระดานจับคู่ของกริยาคำสุดท้ายที่เรียนจบแล้ว
- **Why:** ให้ผู้เรียนย้อนกลับไปขั้นก่อนหน้าของ flow กริยา
- **Impact:** เปลี่ยนเฉพาะปุ่มในหน้าสรุป Verben Lektion 1

## 2026-10-05 — คงกระดานจับคู่และกลับมาหน้าเดิม

- **What changed:** ยกเลิกหน้าคั่น “จับคู่ครบแล้ว” และคงคู่ที่ถูกบนกระดานพร้อมปุ่มไปต่อ; บันทึกหน้าที่เปิดอยู่และกลับมาหน้าเดิมอัตโนมัติ
- **Why:** ให้ผู้เรียนดูคู่ที่ทำไว้และเรียนต่อได้โดยไม่เริ่มจากหลักการผันทุกครั้ง
- **Impact:** เฉพาะ Verben Lektion 1; เข้าครั้งแรกยังเปิดหลักการผัน และเริ่มจับคู่ใหม่เมื่อกดเรียนซ้ำ

## 2026-10-05 — ตรวจสอบ progress กริยาที่กู้คืนจากข้อมูลเก่า

- **What changed:** หน้า “จับคู่ครบแล้ว” และหน้าสรุปจะแสดงจากคู่ที่บันทึกไว้และตรวจยืนยันว่าถูกครบทุกข้อ; สถานะเก่าที่มีคำตอบผิดจะกลับไปยังกระดานจับคู่พร้อมเก็บเฉพาะคู่ที่ถูก
- **Why:** ป้องกัน progress จากรูปแบบกิจกรรมเดิมที่ยังมีสถานะผิดพลาด ทำให้แสดงว่าเรียนครบทั้งที่ยังมีคู่ไม่ถูก
- **Impact:** ปรับเฉพาะการกู้คืน progress ของกิจกรรมกริยา Lektion 1 ในเบราว์เซอร์นี้; บันทึกสถานะที่กำลังเรียนซ้ำแยกเพื่อคงพฤติกรรมเรียนซ้ำหลัง reload; ไม่เปลี่ยนข้อมูลหรือระบบ progress ของทักษะอื่น

## 2026-10-05 — ตรวจคำตอบกริยาทันทีและเก็บเฉลยไว้ท้ายบท

- **What changed:** เปลี่ยนกิจกรรมเป็นลากรูปผันลงช่องประธานและตรวจทันที; รูปที่ถูกแสดงสีเขียว รูปที่ผิดแสดงสีแดงชั่วครู่และกลับคลังคำ; เมื่อจับคู่ครบจึงไปต่อโดยไม่แสดงเฉลยรายคำ เฉลยอยู่ในตารางสรุปท้ายบท
- **Why:** ให้ผู้เรียนได้รับ feedback ระหว่างเรียนและพบเฉลยรวมหลังจบบท
- **Impact:** เพิ่ม drag-and-drop โดยยังรองรับแตะเลือกบนจอสัมผัส; ยกเลิกปุ่มตรวจและผลเฉลยรายคำ; คำตอบที่ถูกบันทึกในกิจกรรมค้างไว้จะคงอยู่ ส่วนคำตอบผิดเก่าจะถูกคืนสู่คลังเมื่อโหลดข้อมูลใหม่


## 2026-10-05 — เปลี่ยนชื่อปุ่มย้อนจากหน้าสรุป

- **What changed:** เปลี่ยนป้ายปุ่มหน้าสรุป Verben จาก “กลับหน้าบทเรียน” เป็น “ย้อนกลับ”
- **Why:** ใช้ข้อความปุ่มสั้นและตรงกับรูปแบบย้อนกลับที่ผู้ใช้ต้องการ
- **Impact:** เปลี่ยนเฉพาะข้อความบนปุ่ม โดยยังกลับไป Lektion 1 เหมือนเดิม

## 2026-10-05 — จัดลำดับปุ่มท้ายกิจกรรมผัน

- **What changed:** วาง “ย้อนกลับ” ทางซ้ายและ “ตรวจการจับคู่” ทางขวาในแถวควบคุมด้านล่าง
- **Why:** ให้ตำแหน่งปุ่มตรงกับลำดับที่ผู้ใช้คาดหวัง
- **Impact:** ปรับเฉพาะลำดับปุ่มในกิจกรรม Verben ของ Lektion 1


## 2026-10-05 — ย้ายปุ่มย้อนกลับใต้กิจกรรมผัน

- **What changed:** ย้ายปุ่มกลับ Introduction ไว้ใต้กระดานจับคู่และเปลี่ยนชื่อเป็น “ย้อนกลับ”; ลดปุ่ม “ตรวจการจับคู่” จากเต็มความกว้างเป็นปุ่มขนาดพอดีและจัดไว้กึ่งกลาง
- **Why:** จัด navigation ไว้ท้ายกิจกรรมและลดน้ำหนักปุ่มตรวจคำตอบ
- **Impact:** เปลี่ยนเฉพาะหน้า conjugation ของ Verben Lektion 1


## 2026-10-05 — จัดกึ่งกลาง Introduction และขยายคำแปลไทย

- **What changed:** จัดเนื้อหา Introduction และตัวอย่างให้อยู่กึ่งกลาง พร้อมเพิ่มขนาดตัวอักษรคำแปลไทย
- **Why:** ช่วยให้อ่านคำแปลได้ชัดขึ้นและวางเนื้อหาไว้กลางหน้า
- **Impact:** เปลี่ยนเฉพาะการแสดงผล Introduction ของ Verben Lektion 1


## 2026-10-05 — เพิ่มปุ่มไปต่อจากหลักการผัน

- **What changed:** เพิ่มปุ่ม “ไปต่อ” กึ่งกลางด้านล่างของหน้า “หลักการผัน” เพื่อเปิด Introduction ของ kommen
- **Why:** ให้มีทางเดินต่อจากหลักการทั่วไปเข้าสู่คำกริยาคำแรกอย่างชัดเจน
- **Impact:** เปลี่ยนเฉพาะ navigation ในหน้า Grammatik → Verben ของ Lektion 1; ไม่สร้าง exposure จนกว่าจะเปิดกิจกรรมผัน

## 2026-10-05 — เพิ่มคำแปลประธานในหลักการผัน

- **What changed:** เพิ่มคอลัมน์ “คำแปล” ถัดจาก “ประธาน” พร้อมคำแปลไทยทั้ง 6 รูปในตารางหลักการผันของ Verben L01
- **Why:** ช่วยให้ผู้เรียนเข้าใจความหมายของประธานแต่ละรูป
- **Impact:** เพิ่มข้อมูลคำแปลใน metadata verbPrinciples.rows ผ่าน migration ของ L01 เท่านั้น; รูปผันและประวัติผู้เรียนไม่เปลี่ยน


## 2026-10-05 — แท็บหลักการผันและตำแหน่งเรียนซ้ำ

- **What changed:** เพิ่มแท็บ “หลักการผัน” ก่อน kommen และเปิดเมื่อเข้า Verben ใช้หัวข้อ “กริยาผันตามประธาน” กับตาราง Endung ไม่มีปุ่มเริ่มเรียน และตัดตัวอย่าง heißen/sein ออกจากหมายเหตุ; ย้ายปุ่มเรียนซ้ำไปด้านขวาของคำอธิบายใต้หัวข้อ
- **Why:** ให้ผู้เรียนเห็นหลักการสังเกตรูปผันก่อนเลือกกริยา และจัดตำแหน่งปุ่มตามที่ผู้ใช้ระบุ
- **Impact:** เพิ่ม metadata verbPrinciples ใน Supabase เฉพาะ L01; เปลี่ยนข้อกำหนดเดิมที่ไม่เพิ่มแท็บตามคำขอใหม่ กิจกรรมที่ค้าง/ประวัติเดิมคงอยู่และเลือกแท็บเพื่อเรียนต่อได้ ไม่บันทึก exposure จากหลักการผัน


## 2026-10-05 — ตำแหน่งปุ่มเรียนซ้ำของ Verben

- **What changed:** ย้ายปุ่มเรียนซ้ำไปด้านขวาบนแถวเดียวกับลิงก์กลับ ใช้รูปแบบการวางเดียวกับหมวดคำศัพท์ และแสดงเมื่อคำปัจจุบันเคยเรียนจบแล้ว
- **Why:** ให้ตำแหน่ง action สอดคล้องกันระหว่างหมวด
- **Impact:** แท็บกริยาเรียนซ้ำเฉพาะคำ หน้าสรุปเรียนซ้ำทั้ง 4 คำ; ใช้ logic เดิมและคงประวัติ/สถานะเรียนจบ


## 2026-10-05 — เรียน Verben ซ้ำทั้งชุดหรือรายคำ

- **What changed:** เพิ่ม “เรียนซ้ำ” ในหน้าสรุป และ “เรียนซ้ำคำนี้” ในหน้าผลจับคู่ของ Verben Lektion 1 เริ่มใหม่จาก Introduction และสลับตำแหน่งคำตอบ
- **Why:** ให้ผู้เรียนกลับมาทำกิจกรรมรอบใหม่ได้หลังเรียนจบ
- **Impact:** ล้างเฉพาะ draft การจับคู่และผลหน้ากิจกรรมของคำที่เลือก คงสถานะเรียนจบและประวัติในฐานข้อมูลทั้งหมดไว้; รอบใหม่บันทึกตำแหน่งผ่าน localStorage เดิม ไม่เปลี่ยน mastery/review หรือบทเรียนอื่น


## 2026-10-05 — Introduction ก่อนการผันกริยา Lektion 1

- **What changed:** เพิ่ม Introduction ภายใน tabs เดิมของ kommen, heißen, lernen, sein พร้อมปุ่มเรียนการผันและย้อนกลับ; sein แสดง 3 ตัวอย่างกับคำแปลตามบริบท
- **Why:** ให้รู้ความหมายและเห็นประโยคก่อนเรียนรูปผัน
- **Impact:** เนื้อหาอยู่ใน Supabase content_lessons.data.verbIntroductions ผ่าน migration; ไม่เพิ่ม practice items หรือแก้ mastery/review กิจกรรมจับคู่ สี endings และตารางสรุปคงเดิม localStorage เก็บขั้น Introduction เพิ่ม โดยข้อมูลเก่า resume กิจกรรมเดิมและไม่เสียผลจับคู่; exposure เริ่มเมื่อเห็นกิจกรรมรูปผันเท่านั้น


## 2026-10-04 — คืนคำอ่าน Ö เป็น öh

- **What changed:** คืน pronunciation reference ของ Ö จาก “öööh” เป็น “öh”
- **Why:** ผู้ใช้ต้องการกลับไปใช้คำอ่านก่อนหน้าหลังทดลองยืดเสียงแล้ว
- **Impact:** เปลี่ยนเฉพาะเสียงสังเคราะห์ Ö

- **Impact:** ป้องกันข้อผิดพลาด `Session position changed`; คำตอบผิดจบทันที ส่วนคำตอบถูกเลือก confidence ก่อนดำเนินต่อ

## 2026-10-02 — Learning History เป็นหลักฐานความก้าวหน้า

- **What changed:** กำหนดให้ Learning History เป็น source evidence และ `KnowledgeState` เป็น derived state; Progress ต้องอ่านจากหลักฐานจริง ไม่ใช้ completion percentage แทน
- **Why:** ต้องสะท้อนว่าเห็นอะไร ตอบอะไร และผิดมิติใด โดยไม่สร้างสถานะ Learned จากการมี content ในระบบ
- **Impact:** เพิ่ม/ใช้ ItemExposure, LearningAttempt, AttemptEvidence, KnowledgeState, PracticeSession และ SessionItem; legacy aggregate ไม่ถูกแปลงเป็น Learning History ปลอม

## 2026-10-02 — Practice แยกจาก Learn

- **What changed:** Practice เป็น independent entry point และผู้เรียนไม่ต้องผ่าน Learn ซ้ำทุกครั้ง
- **Why:** ผู้เรียนควรกลับไปฝึกสิ่งที่เคยเรียนได้ทันที
- **Impact:** Learned item เข้า Practice ได้โดยตรง; Practice ต้องกรอง Not Seen items ออก และ scope ที่ไม่มี Learned item แสดง Empty State พร้อมทางไปเรียน

## 2026-10-02 — Learned boundary และการวัดผล

- **What changed:** Content ที่มีในระบบไม่นับว่า Learned; เฉพาะการเห็น item ผ่าน Learn activity ทำให้เป็น Seen/Learned และ eligible สำหรับ Practice/Review
- **Why:** ป้องกันการทดสอบเนื้อหาที่ยังไม่ได้เรียนและทำให้ความก้าวหน้ามีหลักฐาน
- **Impact:** Learn ต้อง persist exposure; Practice/Review ใช้ exposure เป็น eligibility boundary; noun เรียนเป็น Artikel + Nomen

## 2026-10-02 — Evidence, feedback และ confidence

- **What changed:** รองรับ diagnosis ตาม Word Recall, Artikel, Spelling, Verb Form, Grammar, Sentence Structure และ Application; คำตอบผิดให้ immediate corrective feedback และเก็บ error dimensions ทั้งหมด; คำตอบถูกถาม confidence “ง่าย/ต้องคิด/เดา”
- **Why:** แยกชนิดความรู้ที่ต้องฝึกและเก็บหลักฐานที่ Progress/Review นำไปใช้ได้
- **Impact:** Attempt เก็บ response time เป็น evidence โดยไม่มี time limit; ตอบช้าไม่ถือว่าผิด; Session Summary ยึด first attempt

## 2026-10-02 — Persist และ resume Practice Session

- **What changed:** Incomplete Practice Session ต้องอยู่ได้เมื่อเปลี่ยนหน้า/เปิดใหม่ และ resume ต่อได้
- **Why:** ผู้เรียนไม่ควรเสียตำแหน่งหรือคำตอบระหว่างรอบ
- **Impact:** PracticeSession/SessionItem และ Attempt/confidence ต้อง persist; Learning History คงเป็นหลักฐานถาวร

## 2026-10-02 — Review แยกจาก Practice

- **What changed:** เพิ่ม “ทบทวน” เป็นหัวข้อแยกจาก “แบบฝึกหัด”; Review เป็น system-directed ส่วน Practice เป็น user-directed
- **Why:** ผู้ใช้ต้องการแยกการเลือกฝึกเองออกจากคิวทบทวนที่ระบบแนะนำ
- **Impact:** Navigation มี Review แยก; คิวอาศัยผลล่าสุดและ confidence โดย error ที่ยังต้องคิด/เดาอยู่ในคิว ส่วนล่าสุดที่ถูกและง่ายออกจากคิว

## 2026-10-02 — Pending correct attempt และตัด Response Time ออกจาก MVP

- **What changed:** คำตอบถูก persist ทันทีเป็น Pending และจะ Completed หลังเลือก `easy`, `thought` หรือ `guess`; คำตอบผิด Completed ทันที. Pending ไม่ถูกใช้ใน Review, Progress หรือ KnowledgeState และ session resume กลับมาขั้น confidence ของข้อเดิม. ตัด Response Time ออกจาก learning logic; คง `response_ms` ใน schema ได้เพื่อ compatibility.
- **Why:** confidence เป็นส่วนหนึ่งของหลักฐานคำตอบที่ถูก และเวลาที่รวมช่วงพัก/ออกจากเว็บไม่ใช่หลักฐานที่จำเป็นสำหรับ MVP.
- **Impact:** Review/Progress/KnowledgeState ใช้เฉพาะ Completed attempt; ไม่บันทึก timer จาก client และ KnowledgeState SQL view กรอง Pending. เพิ่ม migration แบบ additive ตั้ง default ให้ column เดิม โดยไม่ลบข้อมูล/column. ไฟล์หลัก: `src/lib/learning.ts`, `src/components/practice.tsx`, `src/components/learning-pages.tsx`, `supabase/migrations/20261003000000_completed_attempts_no_response_time.sql`, `tests/learning.test.ts`, `tests/learning-database.mjs`, `tests/learning-browser.mjs`.

## 2026-10-04 — จับคู่คำศัพท์หลักกับภาพใน Lektion 1

- **What changed:** เพิ่มหัวข้อย่อยคำศัพท์หลักเป็น 5 หน้า 26 รายการ: คำทักทาย 4 คำ, คำบอกลา 3 คำ, ชื่อ-สกุล 3 คำ, ประเทศ 11 คำ และความรู้สึก 5 คำ; เพิ่มหน้าถัดไปให้ปลดล็อกหลังจับคู่หน้าก่อนหน้าครบ; ใช้ธงเป็นภาพจับคู่ประเทศและเพิ่มภาพประกอบชื่อกับความรู้สึก; การจับคู่ยังเลือกคำหรือภาพก่อนก็ได้, ตอบผิดให้ลองใหม่, ตอบถูกย้ายไปการ์ดคู่แนวตั้งพร้อมคำแปลไทย/คำอ่านในวงเล็บ, มีปุ่มย้อนกลับและ “ไปต่อ”, ไม่มีคะแนน/เสียง/ข้อความแจ้งว่าครบ/ป้าย “เรียนแล้ว” บนการ์ด; สถานะหัวข้อแสดงเรียนแล้วเมื่อจับคู่ครบทั้ง 26 รายการ
- **Why:** ผู้เรียนต้องการเรียนคำศัพท์ผ่านการจับคู่ภาพในเมนูบทเรียน
- **Impact:** สถานะชุดภาพ 26 รายการเก็บใน localStorage แยกจาก Vocabulary Learning, Practice eligibility, Progress mastery และ Learning History เดิม; ใช้รายการประเทศ 10 คำจาก catalog เดิมและเพิ่ม Australien ในเนื้อหาชุดจับคู่ภาพ โดยไม่เปลี่ยน catalog หรือ Practice; เพิ่มภาพประกอบที่ปรับขนาดแล้วใน `public/images/lektion-1-core-vocabulary-images/`.

## 2026-10-04 — แสดงกรอบแดงเมื่อจับคู่คำศัพท์ผิด

- **Why:** ช่วยให้ผู้เรียนเห็นตำแหน่งคู่ที่ตอบผิดได้ทันที
- **Impact:** เพิ่ม feedback ทางสายตาในกิจกรรมจับคู่ภาพ โดยไม่เปลี่ยนการบันทึกสถานะการเรียนรู้หรือการให้คะแนน

- **Impact:** หมวดประเทศมี 15 คู่; ชุดคำศัพท์หลักเพิ่มจาก 26 เป็น 30 รายการ และสถานะความคืบหน้ารวมแสดงจำนวนใหม่โดยอัตโนมัติ

- **Impact:** เปลี่ยนปลายทางและข้อความปุ่มบน Alphabet Board โดยไม่เปลี่ยนสถานะการเรียนรู้
