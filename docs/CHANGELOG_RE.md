# Requirement & Experience Changelog

## 2026-10-04 — คืนคำอ่าน Ö เป็น öh

- **What changed:** คืน pronunciation reference ของ Ö จาก “öööh” เป็น “öh”
- **Why:** ผู้ใช้ต้องการกลับไปใช้คำอ่านก่อนหน้าหลังทดลองยืดเสียงแล้ว
- **Impact:** เปลี่ยนเฉพาะเสียงสังเคราะห์ Ö

## 2026-10-04 — ยืดเสียงสระของ Ö

- **What changed:** เปลี่ยนคำอ่านเสียงสังเคราะห์ Ö จาก “öh” เป็น “öööh” เพื่อให้ browser voice ยืดเสียงสระ
- **Why:** ผู้ใช้ต้องการเสียงคล้าย “เออ” ที่มีหางเสียงยาวขึ้น
- **Impact:** เปลี่ยนเฉพาะข้อความเสียงของ Ö โดยไม่ลดอัตราพูดทั้งคำ

## 2026-10-04 — ทดลองคำอ่าน Ö แบบตัวพิมพ์เล็ก

- **What changed:** เปลี่ยนข้อความเสียงของ Ö จาก “oe” เป็น “öh”
- **Why:** ตัว Ö พิมพ์ใหญ่ถูก browser voice อ่านเป็นชื่ออักษร และ “oe” ถูกอ่านแยก; เทียบกับรูปแบบ “Üh” ที่ใช้กับ Ü
- **Impact:** เปลี่ยนเฉพาะข้อความที่ส่งให้เสียงสังเคราะห์ของ Ö

## 2026-10-04 — ทดลองคำอ่าน Ö เป็น oe

- **What changed:** เปลี่ยนข้อความเสียงของ Ö จาก “Ö” เป็น “oe”
- **Why:** German voice อ่านชื่ออักษร “Ö” พร้อมชื่อ Umlaut ต่อท้าย; ผู้ใช้ต้องการลองรูปเขียนทดแทน
- **Impact:** เปลี่ยนเฉพาะข้อความที่ส่งให้เสียงสังเคราะห์ของ Ö

## 2026-10-04 — ปรับเสียงสังเคราะห์ตัว Ö

- **What changed:** เปลี่ยนข้อความเสียงของ Ö จาก “Öh” เป็น “Ö”
- **Why:** German voice ที่ผู้ใช้ฟังออกเสียง “Öh” สั้นและคล้าย “อิว อะ”
- **Impact:** ส่งตัวอักษร Ö ให้ browser voice อ่านโดยตรง; เปลี่ยนเฉพาะเสียง Ö

## 2026-10-04 — ทดลองคำอ่าน C เป็น Ceh

- **What changed:** เปลี่ยน pronunciation reference ของ C จาก “Tsee” เป็น “Ceh” โดยคงอัตราพูดเดิม
- **Why:** ผู้ใช้ต้องการทดลองฟังคำอ่านรูปแบบนี้
- **Impact:** เปลี่ยนเฉพาะเสียงสังเคราะห์ตัว C

## 2026-10-04 — อธิบายความต่างของเสียงสังเคราะห์ Alphabet

- **What changed:** เปลี่ยนข้อความเป็น “เสียงสังเคราะห์อาจแตกต่างกันตามเครื่องและเบราว์เซอร์ที่ใช้เรียน” และคงสีเขียวหม่น
- **Why:** ผู้เรียนควรรู้ว่าเสียงที่ได้ยินขึ้นอยู่กับ voice ที่ติดตั้งในอุปกรณ์ ไม่จำเป็นต้องเหมือนกันทุกเครื่อง
- **Impact:** อธิบายความแตกต่างของเสียงอุปกรณ์; ข้อความ error จริงยังคงแสดงเมื่อไม่มี German voice หรือเล่นเสียงไม่สำเร็จ

## 2026-10-04 — เพิ่มคำแนะนำการออกเสียง ß

- **What changed:** เพิ่มคำแนะนำในกิจกรรม Find Sound ของ ß ว่าออกเสียงเป็น “ส” ไม่ก้อง เหมือน ss (scharfes S)
- **Why:** แยกชื่ออักษร Eszett ออกจากเสียงที่ตัวอักษรแทน
- **Impact:** แสดงคำแนะนำเฉพาะตอนเรียนตัว ß; ไม่เปลี่ยนเสียงสังเคราะห์หรือกิจกรรมตัวอักษรอื่น

## 2026-10-04 — เพิ่มคำแนะนำการออกเสียง Ä

- **What changed:** เพิ่มคำแนะนำในกิจกรรม Find Sound ของ Ä ว่าให้ออกเสียงคล้ายสระ “แอ”
- **Why:** ช่วยให้ผู้เรียนเทียบเสียง Ä กับเสียงสระไทยที่ใกล้เคียง
- **Impact:** แสดงคำแนะนำเฉพาะตอนเรียนตัว Ä; ไม่เปลี่ยนเสียงสังเคราะห์หรือกิจกรรมตัวอักษรอื่น

## 2026-10-04 — เพิ่มคำแนะนำการออกเสียง Ö

- **What changed:** เพิ่มคำแนะนำในกิจกรรม Find Sound ของ Ö ว่าให้ออกเสียงคล้าย “เออ” โดยห่อริมฝีปากเป็นรูป “โอ”
- **Why:** ช่วยให้ผู้เรียนเข้าใจตำแหน่งปากและเสียงของสระ Ö
- **Impact:** แสดงคำแนะนำเฉพาะตอนเรียนตัว Ö; ไม่เปลี่ยนเสียงสังเคราะห์หรือกิจกรรมตัวอักษรอื่น

## 2026-10-04 — เพิ่มคำแนะนำการออกเสียง Ü

- **What changed:** เพิ่มคำแนะนำในกิจกรรม Find Sound ของ Ü ว่าให้ออกเสียงคล้าย “อือ” โดยห่อริมฝีปากเป็นรูป “อู”
- **Why:** ช่วยให้ผู้เรียนเข้าใจตำแหน่งปากและเสียงของสระ Ü
- **Impact:** แสดงคำแนะนำเฉพาะตอนเรียนตัว Ü; ไม่เปลี่ยนเสียงสังเคราะห์หรือกิจกรรมตัวอักษรอื่น

## 2026-10-04 — คืนคำอ่านตัว E เป็นค่าเดิม

- **What changed:** คืน pronunciation reference ของ E จาก “E” เป็น “Eh”
- **Why:** ผู้ใช้ฟังแล้วเห็นว่าค่าเดิมใกล้เคียงเสียงที่ต้องการที่สุด
- **Impact:** คืนเฉพาะเสียง E; ตัวอักษรอื่นไม่เปลี่ยน

## 2026-10-04 — ส่งชื่ออักษร E ให้เสียงเยอรมันอ่านโดยตรง

- **What changed:** เปลี่ยนข้อความเสียง E จาก “ee” เป็น “E”
- **Why:** browser voice อ่าน “ee” ซ้ำเป็น “อีอี”
- **Impact:** ให้เสียงสังเคราะห์ภาษาเยอรมันอ่านชื่ออักษรโดยตรง; เปลี่ยนเฉพาะ E

## 2026-10-04 — ปรับคำช่วยออกเสียงตัว E

- **What changed:** เปลี่ยนข้อความที่ส่งให้เสียงสังเคราะห์ของ E จาก “Eh” เป็น “ee”
- **Why:** เสียงจาก browser voice ยังไม่ใกล้เสียง E เยอรมัน /eː/ หรือ “เอ” ตามต้องการ
- **Impact:** เปลี่ยนเฉพาะเสียง E ใน Alphabet; ตัวอักษรอื่นไม่เปลี่ยน

## 2026-10-04 — แก้คำช่วยออกเสียงตัว F

- **What changed:** เปลี่ยนข้อความที่ส่งให้เสียงสังเคราะห์ของ F จาก “Eff” เป็น “Äff” เพื่อให้อ่านเป็นพยางค์เดียว
- **Why:** browser voice อ่าน “Eff” คล้ายสะกดชื่อ E, F, F แยกกัน
- **Impact:** เปลี่ยนเฉพาะเสียงตัว F ใน Alphabet; ตัวอักษรอื่นไม่เปลี่ยน

## 2026-10-04 — ปรับเสียงตัว C ให้มีเสียงสระท้ายยาวขึ้น

- **What changed:** เปลี่ยน pronunciation reference ของ C จาก “Tseh” เป็น “Tsee” และคืนอัตราสังเคราะห์เป็น 0.8 เท่ากับตัวอื่น
- **Why:** การลดความเร็วทำให้ปลายเสียงฟังเหมือนถูกตัด; ต้องการให้เสียง “เซ” ต่อเนื่องและมีหางคล้ายเสียง D
- **Impact:** ปรับเฉพาะข้อความที่ส่งให้ browser voice สำหรับ C; ตัวอักษรอื่นไม่เปลี่ยน

## 2026-10-04 — ยืดเสียงตัว C ใน Alphabet

- **What changed:** ลดอัตราพูดสังเคราะห์เฉพาะตัว C จาก 0.8 เป็น 0.68 เพื่อให้เสียงยาวขึ้น
- **Why:** เสียงตัว C ที่สังเคราะห์ออกมาสั้นกว่าตัวอื่นและฟังยาก
- **Impact:** เปลี่ยนเฉพาะความเร็วเสียง C; ตัวอักษรอื่นใช้ค่าเดิม

## 2026-10-04 — ปรับ Alphabet Learning Flow

- **What changed:** Alphabet ใช้ Listen and Choose / Find Sound สลับกันตาม content config, เรียนต่อเนื่องโดยไม่มีหน้าจบกลุ่ม, เลือกผิดแล้วไม่เปิดเผยคำตอบ, บันทึก learned IDs, resume position และตำแหน่ง replay แยกกัน; กิจกรรม Umlaut/Eszett แสดง instruction ตามกลุ่ม, ปุ่มกลับ Board อยู่แถวเดียวกับปุ่มนำทางกิจกรรม, Board มีปุ่ม “เรียนใหม่” อยู่แถวเดียวกับ “กลับ Wortschatz”, และหน้า Wortschatz แสดงการ์ด ABCD ไม่มีจำนวนรายการ โดยวางป้ายหลังชื่อบท: “เรียนแล้ว” เมื่อครบทุกตัวและ “เรียนซ้ำ” ระหว่าง replay โดยไม่เปลี่ยน learned state
- **Why:** ให้กิจกรรมสอดคล้องกับเป้าหมายเสียง↔ตัวอักษร และผู้เรียนกลับมาเรียนต่อหรือย้อนฟังได้โดยไม่เสียความก้าวหน้า
- **Impact:** สถานะ Alphabet prototype เก็บใน localStorage แยกจาก Practice/Progress mastery; การย้อนกลับไม่ลดตำแหน่งเรียนต่อ; audio assets และระบบเสียงเดิมไม่เปลี่ยน

## 2026-10-03 — ทำ Vocabulary Learning prototype เป็นชุดสำหรับ Lektion 1

- **What changed:** เปลี่ยนเฉพาะ `/learn/L01/vocabulary` เป็นชุดละ 4 คำ พร้อม INTRODUCE, RECOGNIZE, GUIDED RECALL, RECALL และ CONTEXT ที่สลับคำในชุด; คำที่หลายครั้งยังติดจะถูกแทรกกลับมาเรียนภายหลัง มี summary โดยไม่อ้าง mastery และ developer-only Debug panel พร้อม reset
- **Why:** ต้องการให้ Learn ช่วยสร้างความจำเริ่มต้น แทนการให้ผู้เรียนกดยืนยันคำศัพท์ทีละคำเพื่อสร้าง exposure
- **Impact:** Vocabulary state และ learning events ของ Lektion 1 เก็บใน localStorage แยกจาก Practice/Review, Practice attempts และ legacy `ItemExposure`; `learningCompleted` เกิดเมื่อจบกิจกรรมครบชุด ส่วน Lektion/ทักษะอื่นและหน้า Practice ไม่เปลี่ยน

## 2026-10-03 — ปรับ flow เรียนคำศัพท์ให้มีการดึงคำตอบจากความจำ

- **What changed:** หน้าเรียนคำศัพท์เริ่มจากความหมายภาษาไทย ให้ผู้เรียนลองนึกคำเยอรมันพร้อม Artikel ก่อนกดแสดงคำตอบ และกดยืนยันว่าเรียนคำนี้แล้วจึงบันทึก exposure; ปิดทางไปแบบฝึกจนกว่าจะบันทึก exposure สำเร็จ
- **Why:** การเปิดหน้าหรือเห็นคำศัพท์ทันทีไม่เพียงพอที่จะนับว่าได้เรียนคำนั้น
- **Impact:** คำศัพท์ใหม่จะเข้า Practice/Review และนับใน Progress หลังผ่านขั้นแสดงคำตอบและยืนยันเท่านั้น; ข้อมูล exposure เก่าคงเดิม ส่วน Learn ทักษะอื่นไม่เปลี่ยน

## 2026-10-03 — ซ่อนกล่อง session ที่เล่นค้างจากหน้าหลัก

- **What changed:** เอากล่อง “ฝึกต่อ” ของ session ที่ยังไม่จบออกจากหน้าแรก, แบบฝึกหัด, ทบทวน และความก้าวหน้า
- **Why:** ผู้ใช้ต้องการไม่ให้กล่อง session ค้างแสดงบนเมนูทั้งสี่หน้า
- **Impact:** ประวัติและสถานะ session ยังคงอยู่ และ route `/session?id=...` ยังเปิด session เดิมต่อได้; ไม่มีแบนเนอร์ลัดบนหน้าที่ระบุ

## 2026-10-03 — คืนหน้าตาหน้าแรกเดิม

- **What changed:** คืนกล่องต้อนรับพร้อมภาพ Hallo!, การ์ดสถิติพร้อมไอคอน, การ์ดระดับ A1.1/A1.2, กิจกรรมรายสัปดาห์ และแถบทบทวนจากหน้าแรกเดิม พร้อมคืนหน้ารอโหลดแบบเดิม
- **Why:** ผู้ใช้ต้องการหน้าตาก่อนถูกแทนด้วยหน้าแรกแบบย่อ
- **Impact:** คง Supabase catalog, ปุ่มเข้า Practice โดยตรง และการทำ session ต่อ ตัวเลขอ้างอิง exposure/Completed attempts; ความคืบหน้าระดับแสดงเนื้อหาที่เคยเรียน ไม่อนุมานว่าจำได้จากการเปิดเรียน

## 2026-10-03 — ย้ายคลังเนื้อหาไป Supabase

- **What changed:** เพิ่มตาราง `content_lessons` และ `content_items` พร้อมเนื้อหาเดิม 12 บท / 260 รายการ และเปลี่ยนหน้าเรียน/ฝึก/ทบทวน/ความก้าวหน้าให้อ่านคลังเนื้อหาจาก Supabase มีลำดับและสถานะ draft/published/archived สำหรับการจัดการเนื้อหาในอนาคต
- **Why:** ให้เพิ่มหรือแก้เนื้อหาจากระบบแอดมินในอนาคตได้โดยไม่แก้โค้ดเว็บ
- **Impact:** คงรหัส ลำดับ รูปผัน ตัวเลือก และคำตอบเดิม ไม่แก้ตารางประวัติ ไม่สร้าง exposure จากการโหลด catalog และไม่เปลี่ยน session snapshot; โหลดเนื้อหาก่อน import ข้อมูลเก่า ป้องกัน import ขณะ catalog ว่าง หากโหลดไม่ได้แสดงปุ่มลองใหม่ ผู้เรียนอ่านได้เฉพาะเนื้อหาเผยแพร่และแก้ไขคลังไม่ได้ ระหว่างที่ยังไม่มีตาราง (`PGRST205`) ใช้สำเนาเดิมชั่วคราวเพื่อไม่ขัดจังหวะการเรียน หลังรัน migration และโหลดใหม่จะใช้ฐานข้อมูล รายละเอียดใน `docs/content-database.md`

## 2026-10-03 — เรียนการผันกริยาทีละคำ

- **What changed:** หน้าเรียนผันกริยาแสดงรายการเรียงซ้ายไปขวา บังคับเริ่มคำแรกและให้ย้อนดูคำที่เรียนแล้วได้ จับคู่ด้วยการแตะรูปกริยาก่อนแล้วแตะช่องคำตอบข้างประธาน เก็บตำแหน่ง/ผลเพื่อกลับมาเรียนต่อ และเพิ่มแท็บ “สรุป” ต่อจาก `sein` เพื่อเปิดตารางรวมประธานกับกริยารูปเดิมหลังเรียนครบ พร้อมทางไปบทเรียนหรือแบบฝึก ผลหลังตรวจเน้นส่วนลงท้าย; `heißt` เน้น `ßt`, `bin/bist/ist` เน้นทั้งคำ, `sind` เน้น `in`, และ `seid` คงสีเดิม เอาคำอธิบายเสริมและป้าย “ดูแล้ว” ออกจากหน้าฝึก
- **Why:** ทำให้การเรียนเป็นการดึงคำตอบจากความจำโดยตรง และแยกการเรียนรู้จากการวัดผลความมั่นใจของ Practice
- **Impact:** หน้า Learn เก็บ exposure, ความคืบหน้า และสถานะลำดับที่ต้องปลดล็อกไว้โดยไม่แสดงป้าย “ดูแล้ว”; ไม่สร้าง LearningAttempt หรือถาม confidence. รูป `sein` ใช้ `sind` กับ wir/sie และ `seid` กับ ihr โดยแสดงรูปที่ไม่มี ending ชัดเจนเป็นสีเดิม

## 2026-10-03 — บันทึกคู่ผันตามลำดับ Session

- **Impact:** ป้องกันข้อผิดพลาด `Session position changed`; คำตอบผิดจบทันที ส่วนคำตอบถูกเลือก confidence ก่อนดำเนินต่อ

- **Impact:** เพิ่ม/ใช้ ItemExposure, LearningAttempt, AttemptEvidence, KnowledgeState, PracticeSession และ SessionItem; legacy aggregate ไม่ถูกแปลงเป็น Learning History ปลอม

- **What changed:** Practice เป็น independent entry point และผู้เรียนไม่ต้องผ่าน Learn ซ้ำทุกครั้ง
- **Why:** ผู้เรียนควรกลับไปฝึกสิ่งที่เคยเรียนได้ทันที
- **Impact:** Learned item เข้า Practice ได้โดยตรง; Practice ต้องกรอง Not Seen items ออก และ scope ที่ไม่มี Learned item แสดง Empty State พร้อมทางไปเรียน

## 2026-10-02 — Learned boundary และการวัดผล

- **What changed:** Content ที่มีในระบบไม่นับว่า Learned; เฉพาะการเห็น item ผ่าน Learn activity ทำให้เป็น Seen/Learned และ eligible สำหรับ Practice/Review
- **Why:** ป้องกันการทดสอบเนื้อหาที่ยังไม่ได้เรียนและทำให้ความก้าวหน้ามีหลักฐาน
- **Impact:** Learn ต้อง persist exposure; Practice/Review ใช้ exposure เป็น eligibility boundary; noun เรียนเป็น Artikel + Nomen

## 2026-10-02 — Evidence, feedback และ confidence

- **What changed:** รองรับ diagnosis ตาม Word Recall, Artikel, Spelling, Verb Form, Grammar, Sentence Structure และ Application; คำตอบผิดให้ immediate corrective feedback และเก็บ error dimensions ทั้งหมด; คำตอบถูกถาม confidence “ง่าย/ต้องคิด/เดา”
- **Why:** แยกชนิดความรู้ที่ต้องฝึกและเก็บหลักฐานที่ Progress/Review นำไปใช้ได้
- **Impact:** Attempt เก็บ response time เป็น evidence โดยไม่มี time limit; ตอบช้าไม่ถือว่าผิด; Session Summary ยึด first attempt

## 2026-10-02 — Persist และ resume Practice Session

- **What changed:** Incomplete Practice Session ต้องอยู่ได้เมื่อเปลี่ยนหน้า/เปิดใหม่ และ resume ต่อได้
- **Why:** ผู้เรียนไม่ควรเสียตำแหน่งหรือคำตอบระหว่างรอบ
- **Impact:** PracticeSession/SessionItem และ Attempt/confidence ต้อง persist; Learning History คงเป็นหลักฐานถาวร

## 2026-10-02 — Review แยกจาก Practice

- **What changed:** เพิ่ม “ทบทวน” เป็นหัวข้อแยกจาก “แบบฝึกหัด”; Review เป็น system-directed ส่วน Practice เป็น user-directed
- **Why:** ผู้ใช้ต้องการแยกการเลือกฝึกเองออกจากคิวทบทวนที่ระบบแนะนำ
- **Impact:** Navigation มี Review แยก; คิวอาศัยผลล่าสุดและ confidence โดย error ที่ยังต้องคิด/เดาอยู่ในคิว ส่วนล่าสุดที่ถูกและง่ายออกจากคิว

## 2026-10-02 — Pending correct attempt และตัด Response Time ออกจาก MVP

- **What changed:** คำตอบถูก persist ทันทีเป็น Pending และจะ Completed หลังเลือก `easy`, `thought` หรือ `guess`; คำตอบผิด Completed ทันที. Pending ไม่ถูกใช้ใน Review, Progress หรือ KnowledgeState และ session resume กลับมาขั้น confidence ของข้อเดิม. ตัด Response Time ออกจาก learning logic; คง `response_ms` ใน schema ได้เพื่อ compatibility.
- **Why:** confidence เป็นส่วนหนึ่งของหลักฐานคำตอบที่ถูก และเวลาที่รวมช่วงพัก/ออกจากเว็บไม่ใช่หลักฐานที่จำเป็นสำหรับ MVP.
- **Impact:** Review/Progress/KnowledgeState ใช้เฉพาะ Completed attempt; ไม่บันทึก timer จาก client และ KnowledgeState SQL view กรอง Pending. เพิ่ม migration แบบ additive ตั้ง default ให้ column เดิม โดยไม่ลบข้อมูล/column. ไฟล์หลัก: `src/lib/learning.ts`, `src/components/practice.tsx`, `src/components/learning-pages.tsx`, `supabase/migrations/20261003000000_completed_attempts_no_response_time.sql`, `tests/learning.test.ts`, `tests/learning-database.mjs`, `tests/learning-browser.mjs`.
